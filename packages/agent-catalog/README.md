# Agent Catalog

This package owns the sole manually maintained Peers Official signed catalog
envelope:

- `official-catalog.v1.envelope.json`

Desktop embeds this file as its bootstrap snapshot. Station serves an exact
generated byte projection from
`apps/station/app/subserver/agent/catalog/official_catalog_gen.go`.

Regenerate or verify the Station projection from the repository root:

```bash
(cd apps/station/app && go generate ./subserver/agent/catalog)
(cd apps/station/app && go run ./subserver/agent/catalog/generate -check)
```

Do not copy the envelope into a client or server source directory. Publisher
signing happens outside runtime code; Station distributes bytes but is not the
catalog trust root.
