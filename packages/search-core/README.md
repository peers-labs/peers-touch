# Portable Search core

Canonical wire: `model/domain/search/search.proto`, generated by `build.rs`.

- `ports.rs`: object-safe `SearchContributor` (`query / hydrate / resolve`),
  trusted execution context, cooperative operation cancellation.
- `contributor.rs`: declaration, candidate and batch-reply conformance.
- `cache.rs`: bounded memory payloads, shared reads, subscriber detachment,
  monotonic expiry and active operation fences independent from LRU eviction.
- `runtime.rs`: query/hydrate/resolve coordination over a trusted host binding
  and native executor; validates source replies before caching them.
- `requests.rs`: bounded, identity-scoped request admission and cancellation.
- `query.rs / tokenize.rs`: shared CJK/Latin FTS semantics.
- `ranking.rs / cursor/`: fusion and authenticated, expiring continuations.

Hosts implement `SearchExecutor` and `SearchBinding`, execute source futures
and supply original-owner guards. Cache commit
and final publication must be serialized with identity, policy and source
invalidation. A content hit never grants authority. No database, Tauri, HTTP,
UI tree, model provider or Applet runtime is owned here.

Desktop consumes the shared coordinator. Mobile uses the same native contracts;
platform bindings never move credentials, database ownership or navigation into
this crate. Station and Applet binding integration remain separate work.
