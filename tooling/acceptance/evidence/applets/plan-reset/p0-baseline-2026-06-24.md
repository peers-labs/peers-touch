## Allowed Claims

- Desktop `peers.note` runtime path works for the evidence-covered path:
  Desktop AppletManager -> Lynx Host -> Lynx Web runtime -> SDK bridge ->
  Gateway session -> Station-bundled Note service.
- Complex applet candidate gates are strong enough to continue from as
  candidate baseline, including Desktop runtime, product Host real Gateway,
  product shell real Gateway, packaged product window, controlled upstream,
  Web Host candidate, and Android/iOS runtime marker evidence.
- The active execution source has been reset to
  `2026-06-23-applet-capability-completion-plan.md`.

## Forbidden Claims

- Do not claim applet capability is complete.
- Do not claim `L5 COMPLEX_PLATFORM_READY`.
- Do not claim terminal L3 release readiness.
- Do not claim Station Store is implemented.
- Do not claim Applet Box is Station-backed production truth.
- Do not claim a real third-party package has been certified.
- Do not claim manual normal-user acceptance has passed.
- Do not treat synthetic outside-repo package evidence as independent producer
  acceptance.
