## Objective

Complete the Station-owned Access Gate and OAuth source path without using
physical evidence as source completion.

## Current Snapshot

- Station-issued descriptors now bind action identity, schema revision, schema
  digest, attempt, Station, device, lifecycle generation, and a stable
  submission identity.
- Password authentication creates only an attempt-scoped actor candidate until
  the full gate chain is granted; Station finalization then creates one
  attempt-bound session.
- Password, invite, and generic scalar actions use the Rust protobuf transport.
  Bearer and refresh credentials remain in native secure storage while Web
  receives only the public session projection.
- Lost-response retries reuse the same Mobile submission identity. Station
  stores a keyed exact-payload digest, and invite redemption plus attempt
  completion commit in one transaction.
- The Task write set and focused checks now include the accepted generated
  contract, Station handler/persistence, and Rust native session boundaries.
- Rust business transport hardening is isolated in `W2-TRANSPORT`.
- Required simulator proof remains `UNPROVEN` and belongs only to W2-PROOF;
  physical provider proof is optional diagnostics.
