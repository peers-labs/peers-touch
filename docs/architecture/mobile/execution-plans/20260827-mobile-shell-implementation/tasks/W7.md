## Current Snapshot

- Existing native project parity and lifecycle fencing are preserved by
  `W7-SOURCE-SYNC` and `W7-RUNTIME-FENCING`.
- `MS-D23A` now defines PTID/device-bound APNs/FCM/UnifiedPush registration,
  encrypted provider credentials, idempotent mutation/readback, and
  generation/sequence-fenced reconcile callbacks.
- `MS-D23B` fixes one scheduler identifier per environment, exactly-once
  completion, bounded picker requests, and Rust-owned opaque media staging.
- Notification Proto, Station persistence/API, authenticated Rust transport,
  native callback queues, scheduled completion, and media staging are
  source-complete.
- Provider registration retries preserve one canonical request ID and original
  lifecycle-generation commitment, stop after three attempts, and serialize
  concurrent Rust drains.
- Environment changes and logout cancel stale Android/iOS schedules and
  exactly-once complete any active native scheduler callback.
- Full Mobile check, 92 files / 676 tests, 29 focused Rust platform tests,
  Station Notification/session tests, iOS Swift package build, and Android
  Kotlin compile pass.
- Required simulator platform proof belongs to W7-PROOF; physical provider,
  scheduler, picker, and hardware behavior remains optional diagnostics.
