# Chat 本机存储治理 - 产品定义

> **Status**: active
> **Version**: v1.1
> **Created**: 2026-09-26 | **Updated**: 2026-09-27
> **Owner**: Device Messaging Engine

---

## 1. 产品命题

用户应能在 Desktop 与 Mobile 上看清当前设备的 Chat 占用，定位最大的联系人或群聊，
安全清理可再生成缓存，选择少量保留周期，并在清理后看到实际释放空间。

## 2. 硬约束

- 只治理当前设备；Station authority、其他设备和其他参与者不受影响。
- 不保留旧 clear/restore、local-only delete、disappear timer 或伪统计兼容。
- 没有正式历史用户；受影响本机 schema 和 Recovery archive 使用干净新基线。
- 任何清理都保护可靠性、crypto、草稿和活跃传输。
- 成功物理回收必须由真实文件字节下降证明。
- 双端共享同一协议、分类、状态、错误和持久结果。

## 3. 能力

| ID | 能力 | 产品结果 |
|---|---|---|
| CSG-C01 | Chat 存储总览 | 显示当前设备总量、消息、媒体、缓存与系统数据 |
| CSG-C02 | 按会话占用 | 按联系人或群聊显示消息、媒体、合计与最近活跃 |
| CSG-C03 | 清理 Chat 缓存 | 删除可再生成缩略图和媒体，不删除消息或受保护状态 |
| CSG-C04 | 本机保留周期 | 永久、1 年、90 天、30 天，默认永久 |
| CSG-C05 | 按会话本机清理 | 删除已确认边界内的投影与媒体，普通同步不恢复 |
| CSG-C06 | 消息删除语义 | “为我删除”跨本人设备；“撤回”对参与者留痕 |
| CSG-C07 | 物理回收与恢复 | crash-safe journal、compact、字节读回与 Recovery redaction |
| CSG-C08 | 批量清理会话 | 从存储列表明确选择多个会话，逐项清理并报告完整或部分结果 |

Desktop 与 Mobile 均为 `required`；Browser 不在本模块声明范围。

## 4. 用户可见范围

### 设置 > 存储

- 当前设备 Chat 总占用与最近统计时间；
- 消息、媒体与文件、可清理缓存、系统数据；
- “清理 Chat 缓存”；
- 四档“保留消息”；
- 按占用排序、可搜索的会话列表。
- 对当前搜索结果进入管理模式、全选或逐项选择并批量清理；
- 批量确认显示会话数与预计可回收空间，结果显示成功数、失败数与实际释放量。

### 会话详情 > 存储

- 当前会话消息、媒体与合计；
- “清理此设备上的聊天数据”；
- 明确说明只影响当前设备；
- 清理后显示实际释放量或“空间待释放”。

### 消息操作

- `为我删除`：本人所有设备隐藏并清除本地明文。
- `撤回`：按既有权限对参与者留痕并清除内容缓存。
- `清理本机数据`：只释放当前设备空间，不产生 Conversation 业务事件。

## 5. 非目标

- 不提供企业生命周期策略、法律保全、云端套餐或冷归档。
- 不提供自定义天数或按媒体类型的高级规则。
- 不从 Station 按会话重新下载旧明文；完整加密 Recovery 是独立显式流程。
- 不实现阅后即焚。
- 不提供“清空后 24 小时恢复”。
- 不提供无选择范围的“删除所有聊天”；批量操作必须显式选择。
- 不修改 Station authority history。

## 6. 成功指标

| 结果 | 目标 |
|---|---|
| 双端同一动作的语义差异 | 0 |
| 无法解释的消息、草稿、密钥或传输丢失 | 0 |
| 清理成功但物理占用未下降且无明确状态 | 0 |
| retention 误删可靠性或 crypto 状态 | 0 |
| 旧存储语义九维扫描残留 | 0 |
| required 原生 E2E 覆盖 | 100% |

## 7. 产品门

当前状态：`PRODUCT_READY_FOR_ARCHITECTURE`。

Owner 已确认批量清理继续沿用当前设备作用域、不可撤销语义与现有
sequence/hash floor；批量只是显式选择后的多会话操作，不扩大为全局删除。

本次不新增独立原型。双端已有 Storage Section、会话列表、危险动作确认和
单会话清理组件；新增管理模式、Checkbox、批量操作栏及结果反馈可由现有生产组件
直接表达，L2/L3 由最终原生 Journey 截图与交互证据提供。
