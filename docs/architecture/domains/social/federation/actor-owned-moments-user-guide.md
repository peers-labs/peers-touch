# 朋友圈主权架构 v1：用户说明

Desktop 源码已接入公开签名发布、编辑、评论、反应、删除标记和已验证内容读取；Mobile 公开发布会明确拒绝并保留草稿，私密发布继续走原有加密流程。当前尚未完成同源部署和双站 Native 验收。下文说明 v1 产品合同，研发接入与验证状态见 [研发说明](./actor-owned-moments-development.md)。

## 发布与互动

选择「公开」后，帖子、编辑、删除标记、反应和评论由自己的授权设备签名。Station 保存和同步这些操作，不能替用户改写已经签署的正文或冒充用户发布。

网络超时可能发生在操作已经送达之后。客户端保留原操作，重试同一份内容；确认之前不继续创建下一条公开操作。重启后应恢复待确认操作，避免重复发布或跳过历史。

v1 每个账号的公开链只有一台写入设备。另一台设备不能接管公开发布；原设备不可用时暂停公开写入。多设备续写与换设备恢复不属于 v1。

## 公开和私密

公开内容可以复制到关注者所在的 Station。两站短暂断开时，内容可能延迟出现；重连后按顺序补齐。取消关注或屏蔽应停止后续复制。

朋友、圈子、指定人员和仅自己等非公开受众继续使用现有端到端加密流程。公开签名链不会把这些私密正文变成公开内容。

旧客户端和尚未接入签名链的 Mobile 客户端会收到明确的公开写入拒绝。私密能力按原有客户端支持范围继续工作。

## 编辑和删除

圈友是自己的受众名单。管理时添加或移除人员只修改草稿，取消会丢弃这些选择；
保存后按实际成员结果确认。成员读取暂时失败时会禁用管理，避免使用缺失名单保存。

作者名片可拉黑或取消拉黑。拉黑后动态列表过滤该作者，已打开的个人页仍可浏览公共内容。
取消拉黑不会自动恢复之前的朋友关系或已撤销的私密访问。
这两条交互的源码已接入，实际 Native 验证尚未完成。

编辑会追加新版本，不能抹去已经复制的旧版本。删除追加隐藏标记，让正常界面停止展示该对象；已经公开传播的签名历史不能保证被所有副本真正销毁。

自己的公开帖可从「更多 → 编辑」修改正文；附件和公开受众保持不变。保存失败时保留输入，重试使用原操作。当前编辑入口仍待 Native 验证。

公开发布是一项可追溯的信用承诺。需要限制传播时，应在发布前选择适当的私密受众。

## 验证与恢复的边界

已经见过的历史回退、同一位置出现不同内容、签名不匹配或正文与签名事件不符，应停止使用该份内容并给出可定位的错误。

签名不能证明一个从未见过的最新尾部没有被隐藏，也不能恢复已经失去所有副本的数据。v1 不承诺毁站后的全量内容恢复。
