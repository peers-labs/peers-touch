状态：accepted（Owner 2026-11-02 确认）。所有生产链路须取得当前源码的独立证据；逐功能审查的 B01–B10 是基础定位，不是“已有即通过”。

## 评审绑定与操作语义

本候选显式使用工作区交付包 `function-design-skill-20261101/closure-contract.md` 与该包的 `pt-product-design-methodology/SKILL.md` 草案评审；active 准则仍是 `docs/architecture/engineering/acceptance/product-acceptance-criteria.md`，未安装草案。当前本机复审及否定项绑定 `native-review-source-binding.json` 与 `native-trae-review.md`。`candidate-source-binding.json`只绑定被否定的技术线框范围，其观察不迁为当前产品效果证据。

以下是模块唯一的逐操作闭环实例。F01–F52 复用原审查组，语义后缀区分可独立接受、修改或失败的操作；不新增全局 ID 注册表。等价入口复用同一实例，不因按钮数量增加操作。C/J 为父能力/旅程索引，B 为既有源码基础；新增接线全部为生产设计义务，均非生产已实现声明。可操作线框的有界模拟观察另见prototype入口，不将其回填为本矩阵全量通过。

补充基础 **B11 Knowledge/能力目录**：`apps/desktop/src/components/agent/AgentCapabilityInventoryPanel.tsx` 按 KNOWLEDGE 等类型投影能力，保存/删除 binding 和 approvalPolicy；B09 的 `prompt_assembly_service.go:376–425` 已检索获授权 Knowledge 并核对 pinned capability 版本。这里只证明目录和上下文基础，不能据此声称管理→绑定→真实回答闭环已跑通。

每项“入→接→验→反”分别给出真实触发输入、生产后消费者、接收方断言、相关负向/恢复；“据”给出复用基础。身份/Station、任务、Turn/request、资源版本和当前权限必须连续。声明需要保存的对象重开回读；前置失败留草稿，未知副作用先核对，不用通用失败清单替代各项语义。

控制默认、角色生命周期和权限失效仅引用 [状态模型](./product-state-model.md)。接收条件和完成决定仅引用 [产品定义](./product-definition.md)。Architecture 须把下面的领域责任绑定实际接口/协议，Prototype 和 Acceptance 消费同一断言；名称相同或 source 文件存在不证明接线。

## 入口与角色

**F01.navigate**：C01/J02；入：全局 Agent 导航；接：Shell 路由→既有 Agent 选择链；验：唯一一级目的地，任务列表可达；反：返回保留原任务，不生成第二工作台；据：B01/B05。

**F02.enter**：C01/J01；入：正常启动或审阅深链；接：同一 Shell/AgentChat 打开空或已选任务；验：一个 composer，深链不改全局默认落点；反：失效链接解释并回原导航；据：B01/B02。

**F03.search**：C01/J02；入：全局关键字与当前身份；接：Search contributor 查询真实获授权任务/消息/版本→结果列表；验：新增任务和正文可命中、对象标识明确；反：无权标题/片段/数量不泄漏，失败保留查询；据：B08。

**F04.open-hit**：C01/J02；入：命中对象/消息/版本标识；接：Search opener 重新授权→原 Agent/Topic/Portal；验：定位指定对象及位置；反：对象删除/撤权回原查询，不 toast 冒称定位；据：B01/B08。

**F05.switch-role**：C02/J02；入：roster 选中角色；接：既有选择 Owner 恢复该角色任务和草稿；验：会话、工作面一致，无第二选择真源；反：无权/停用角色只读受准历史，不串草稿；据：B02/B05。

**F06.create-role**：C13/J08；入：新建角色及身份输入；接：Profile 保存实体→roster→同一 composer；验：可回读并用于新轮；反：保存失败保留输入，创建不自动获得工具权限；据：B02/B03。

**F07.rename-role**：C13/J08；入：Profile 名称修改；接：身份 Owner 保存→roster/搜索/新消息投影；验：回读同一身份版本；反：保存冲突保留编辑，不覆盖新版本；据：B03。

**F07.purpose**：C13/J08；入：角色用途编辑；接：Profile Owner→角色详情/选择时说明；验：重开显示保存用途，只有已声明参与上下文的字段进入运行；反：失败不丢原值，不把介绍文案冒称规则消费；据：B03。

**F07.avatar**：C13/J08；入：实际图片上传/选择；接：已有头像 Owner→Profile/roster/消息头像；验：实际图像版本重开一致；反：上传或存储失败保留上次有效头像；据：B03。

**F07.reset-avatar**：C13/J08；入：头像选择器 Use initial；接：同一头像 Owner→默认头像投影；验：Profile/roster/新消息重开采用默认；反：失败保留最后有效图，不删除历史身份来源；据：B03。

**F08.soul**：C11/C13/J08；入：独立 SOUL 编辑保存；接：规则 Owner 产生版本→新 Turn 上下文；验：新轮行为与来源采用该版本，旧轮不变；反：并发保存/执行失败保留输入，不混入 AGENTS；据：B03/B05。

**F08.agents**：C11/C13/J08；入：独立 AGENTS 编辑保存；接：规则 Owner→新 Turn 工作规则；验：实际消费及历史版本可解释；反：新旧轮竞争不偷偷换快照，不合并 SOUL；据：B03/B05。

**F09.bind**：C13/C14/J08；入：已有 Skill/MCP 包选择与角色范围；接：extensions Owner 保存→能力发现；验：只出现有效绑定的命令及可用性；反：包失效/保存失败保留选择，绑定不等于授权；据：B03/B04。

**F09.discover**：C13/C14/J08；入：打开现有命令菜单或输入 slash；接：绑定目录→command projection；验：命令归属、参数入口和缺失能力明确；反：过时目录重核对，菜单不冒称执行；据：B02/B03。

**F09.invoke**：C11/C14/J08；入：命令、参数及当前 task/权限；接：工具执行 Owner→真实结果→本任务消息/Portal；验：实际参数被采用，结果所属 Turn 可读；反：执行再授权，拒绝不产生副作用；据：B05/B10。

**F09.unbind**：C13/C14/J08；入：取消角色能力绑定；接：extensions 更新→发现及后续执行准入；验：新轮不能调用已移除能力；反：活动步骤按权限/控制合同处理，不能只藏菜单；据：B03/B05。

**F09.approval-policy**：C03/C13/C14/J08；入：现有能力目录修改审批策略；接：binding Owner 保存版本→后续请求及执行授权；验：新请求采用当前策略，现存 pending 不自动批准；反：收紧权限在实际消费阻断，保存冲突留编辑，策略不代替发布授权；据：B11/B05。

**F10.disable-role**：C02/C13/C18/J08；入：停用当前角色；接：角色生命周期→准入/队列/活动停止/历史投影；验：禁止新执行、历史可读、停止结果可回读；反：停止未知保留任务，不能级联删 threads；据：B02/B03/B05。

**F10.enable-role**：C13/C18/J08；入：恢复被停用角色；接：角色 Owner→可用性目录；验：可显式开始新轮；反：不自动恢复队列、审批或旧进程；据：B03/B05。

**F10.remove-role**：C02/C13/J08；入：明确永久移除角色配置；接：角色 Owner 删除配置→历史安全来源投影；验：历史任务独立保留，当前执行先按停用处理；反：有未知活动不提前完成，历史删除不暗含其中；据：B02/B03/B05。

**F10.replace-role**：C02/C13/C14/J08；入：停用角色旧任务中显式选择可用角色；接：任务 Owner 保留历史→新规则/权限核对→新 Turn；验：新轮来源与角色明确，旧轮仍原快照；反：无可用角色保持只读，不自动换模型或角色；据：B03/B05。

## 任务与队列

**F11.new-task**：C02/J01；入：用户明确新目标与资料；接：现有 composer→Conversation/Topic 任务关系；验：目标和接收条件可回读，独立任务有独立草稿；反：前置失败不产生幽灵已运行任务；据：B02/B05。

**F11.change-goal**：C02/C10/J01/J07；入：同一任务概览显式修改目标、条件和约束；接：原任务 Owner 保存当前上下文及变更历史→新轮→版本核验；验：旧目标与条件可回读、新轮消费当前目标、旧接受失效；反：运行中不换本轮快照，取消不改当前合同，失败保留编辑草稿；据：B02/B05，原型本机上下文消费见 execution-observations，生产接线仍待证明。

**F11.send**：C02/C04/J01；入：已选任务草稿、资料及模型；接：上下文核对→执行接受本轮→消息/结果；验：回执对应输入版本，接受后才清已发送槽；反：拒绝或未知接受先回读，不重复外部写入；据：B02/B05/B10。

**F12.open**：C02/J07；入：列表选择已有任务；接：既有选择/持久化 Owner→会话及工作面；验：目标、结果、位置一致；反：只打开不宣称进程恢复；据：B02/B05。

**F12.continue**：C02/J07；入：同一目标追问/改稿；接：原任务上下文→新 Turn；验：保留结果关系，不因主题词自动建新任务；反：权限变化留草稿并说明恢复；据：B05/B10。

**F12.resume**：C02/C04/J07；入：旧任务显式请求续运行；接：执行宿主重新授权/回读→resume 回执；验：实际恢复点和环境可观察；反：不支持恢复则保留历史并明确新运行，不伪称续进程；据：B10。

**F13.rename-task**：C02/J02；入：标题编辑 Enter 提交；接：任务名称 Owner→列表/Search/通知；验：重开及另端标题一致，目标不变；反：Esc/保存失败保留旧标题或编辑，不改接收条件；据：B02/B05/B08。

**F14.pin**：C02/J02；入：任务置顶；接：任务偏好 Owner→列表排序；验：重开排序一致，运行状态不变；反：冲突/失败回读，不用本地按钮色代替保存；据：B02/B05。

**F14.unpin**：C02/J02；入：取消置顶；接：同一偏好 Owner→正常排序；验：重开不再置顶；反：失败保持最后确认状态及原任务位置；据：B02/B05。

**F15.find-title**：C01/J02；入：列表头部搜索→原位满宽输入→任务/对话/标签关键字；接：同一列表查询→当前标签范围内的命中；验：头部和列表不增高，关闭/Esc恢复控件和焦点；反：无结果保留输入，不宣称全局覆盖；据：B02。

**F15.find-body**：C01/J02；入：当前任务对话正文查找；接：ConversationSearch→具体消息位置；验：计数和定位来自实际正文；反：历史未加载需说明范围，无权正文不搜索；据：B02/B08。

**F16.set-tags**：C02/J02；入：任务菜单→自定义标签增改→保存；接：同一任务 Owner 的标签→任务行、范围选择与搜索；验：重开标签一致，任务身份、结果、运行及队列不变；反：取消不写入，空值忽略、同名去重，标签名不触发执行；据：B02/B05，生产标签接线待补。

**F16.remove-tag**：C02/J02；入：同一标签编辑器移除指定标签并保存；接：任务标签→当前范围与全部任务；验：任务和结果仍可定位，最后一个标签删除不删除历史；反：保存失败保留旧值和编辑，标签范围消失返回全部任务，不启动运行；据：B05。

**F17.delete-one**：C02/C18/J02；入：确认单任务及资源影响；接：生命周期 Owner 停止/清理独占资源→删除历史/索引引用；验：指定对象消失，无活动孤儿；反：共享源不删除，未知停止不删该任务；据：B02/B05/B08/B10。

**F17.delete-many**：C02/C18/J02；入：冻结选中集合并确认逐项影响；接：同一删除 Owner→逐项回执及列表；验：只有已核对项删除，失败项仍可定位；反：不扩大集合、不用一条 toast 隐藏部分失败；据：B02/B05。

**F18.preserve-draft**：C02/C18/J01/J08/J10；入：角色/任务/Settings/工作面切换；接：任务 Owner 的输入与版本编辑草稿→返回原 task/composer/reader；验：正文、附件、选区、基础版本与未发送状态不变，编辑草稿返回仍可继续；反：仅显式放弃清除指定草稿，换身份隔离，不自动发送旧草稿；据：B02/B03。

**F19.reopen**：C02/C18/J01/J07；入：关闭/刷新后重开；接：已有持久化与恢复 Owner→任务、正文编辑草稿、旁聊已保存内容及未提交输入、版本、工作面、最后确认状态；验：独立输入与字节摘要一致，返回原编辑基础版本；反：离线保留安全已读数据并标状态，不清会话，不把组件缓存当作持久化；据：B02/B05/B10，当前原型回归见 continuity-observations。

**F20.enqueue**：C03/J03；入：运行中提交下一轮正文/资料；接：既有队列 Owner 接受→队列内容与顺序；验：排队回执后可回读，成功前轮后才 admission；反：失败/等待/未知/失效暂停，不以 busy 返回代表排队；据：B05。

**F20.edit-queued**：C03/J03；入：admission 前修改指定排队项；接：队列版本更新→后续准入；验：执行采用确认后的输入版本；反：已 admission 改走当前轮控制，冲突不丢编辑；据：B05，编辑绑定待架构核验。

**F20.cancel-queued**：C03/J03；入：取消指定排队项；接：队列取消→准入阻断/回执；验：取消确认后该项不执行；反：竞争已开始则显示真实状态，不假称无副作用；据：B05。

**F20.continue-queue**：C03/C14/J03/J10；入：暂停后显式继续队列；接：执行状态/角色/权限重核对→顺序准入；验：仅有效项开始，采用当前权限；反：未知前轮/停用/过期不准入，草稿不自动重放；据：B05/B10。

**F21.steer**：C03/J03；入：支持宿主的当前轮补充；接：双向执行宿主接受→本轮后续行为；验：回执对应 Turn 与输入；反：不支持时留下一轮草稿，不插消息伪称成功；据：B10，双向绑定待补。

## 人的介入、资料与运行

**F22.stop**：C03/C18/J03；入：停止当前轮；接：cancel Owner→运行端停止/副作用回读→暂停队列；验：最后确认状态和已发生结果明确；反：无回执显示请求中，不自动开始下一项；据：B02/B05/B10。

**F22.stop-all**：C03/C18/J03；入：明确停止并取消本任务队列；接：运行取消及逐项队列取消 Owner→回读；验：确认项不再执行，历史保留；反：部分取消失败/未知逐项展示，不声称全部停止；据：B05/B10。

**F23.answer**：C03/J03；入：当前有效澄清 request 的自由回答/选项；接：request Owner→对应阻塞轮继续；验：采用独立回答，仅释放该请求；反：重复/旧 request 拒绝，切换保留未提交答案；据：B02/B05。

**F23.cancel-answer**：C03/J03；入：取消尚未提交的澄清编辑；接：局部输入 Owner→原 request 继续等待；验：未提交答案不消费；反：不释放其他轮次或擅自回答，停止另用 F22.stop；据：B02/B05。

**F24.approve**：C03/C14/J03；入：有效 request 的工具、参数、资源、影响确认；接：审批 Owner→执行再授权→真实工具结果；验：仅所示动作发生且结果回本轮；反：批准不等于执行完成，变参/撤权必须拒绝；据：B02/B05/B10。

**F24.reject**：C03/J03；入：拒绝所示动作；接：审批 Owner 阻断→未执行/替代决定状态；验：无该动作副作用，用户可继续选替代；反：已执行竞争先回读，不默认执行弱化动作；据：B02/B05。

**F25.stale-request**：C03/C18/J03；入：旧 Turn/request/version 的决定；接：request Owner 校验→只读旧状态；验：不能批准新请求；反：保留当前等待卡，不因旧按钮消失丢新请求；据：B02/B05。

**F25.duplicate**：C03/C18/J03；入：同一决定重复或多端并发提交；接：原 request Owner→同一结果回读；验：副作用恰一次；反：冲突决定返回最终真实状态，不在 UI 去重后漏服务端；据：B02/B05。

**F25.reconcile**：C03/C18/J03/J10；入：断连或未知副作用后回读；接：执行 Owner 核对→已执行/未执行/仍未知；验：恢复依据可解释；反：仍未知不自动重试外部写入；据：B05/B10。

**F26.attach**：C04/C11/J01；入：独立实际文件选择；接：已有附件 Owner 读取/授权→待发送资料；验：字节可核验且选择可回读；反：读取失败留草稿与文件，不用 name/size 代替正文；据：B02/B07。

**F26.consume**：C04/C11/J01；入：本轮获授权的当前有效资料；接：同一上下文 Owner 资料集合及修订号→执行→回答/采用来源/reader；验：新字段覆盖旧字段，同名新版本和后续无附件轮保持更新，未覆盖字段保留；反：排除项不进入未来轮，旧消息字节不改，无权限/未读取不得显示已采用；据：B05/B07，当前原型按独立输入回归，生产绑定仍待证明。

**F48.privacy**：C11/C14/C18/J04/J10；入：来源/模型/日志投影请求；接：原服务端授权与脱敏→用户可读投影；验：凭据只在 Station，raw prompt/密钥/敏感路径不进入投影；反：跨身份、撤权和迟到事件均清理无权缓存；据：B05/B09/B10。

## 操作质量与评审承接

**F49.narrow-return**：C02/C05/C15/J02/J04；入：窄窗口列表/会话/工作面切换及返回；接：既有单列导航→原 task/draft/version/focus；验：无根溢出、位置保留；反：不叠三栏、不因视图切换建任务；据：B01/B02/B07。

**F50.keyboard**：C18/J02/J04/J08；入：Tab/Arrow/Enter/Esc 操作；接：既有菜单/Modal/reader→同一业务动作；验：动作可达、关闭回原按钮；反：不陷焦点、不用无 label 图标隐藏能力缺失；据：B02/B03/B07。

**F50.touch**：C15/C18/J02/J04；入：触摸选择/返回/批注；接：同一操作及平台适配；验：目标可点、选区/草稿不丢；反：不要求手机本地 shell，不以430px截图替代真触摸；据：B02/B07。

**F50.assistive**：C18/J03/J04；入：辅助技术读取状态/决定；接：语义/焦点/状态通知→可操作结果；验：请求范围及验证状态可理解，声明主题对比度符合原 craft；反：不靠颜色或频繁播报表达状态；据：B02/B03/原 craft。

**F51.sync**：C02/C18/J02；入：后台无变化同步；接：既有同步 Owner→稳定投影；验：不重初始化 task/draft，不闪加载条；反：有变化只更新受影响对象；据：B05。

**F51.offline**：C04/C18/J03/J07；入：网络/执行设备断连；接：连接及执行回读→最后确认状态/恢复入口；验：几何、草稿、已读结果保留；反：不清历史、不把本地点击当远端成功；据：B05/B10。

**F51.long-content**：C05/C18/J04；入：长会话/大文件及长输出；接：现有滚动/分页/reader Owner→持续可读与定位；验：滚动边界、返回和布局稳定，声明环境性能有证据；反：不截断冒称完整、不用 build 通过当 Native 性能；据：B05/B07。

**F52.review-consumption**：C10/C18/J01/J06；入：当前产品操作、源身份及各层证据；接：原 Product/Architecture/Prototype/Acceptance Owner 修正→同连接复审；验：报告结论被合同/绑定/注入消费，变更后证据重核对；反：不捏造独立 receipt、不混设计/原型/Native，未检查列明；据：原产品准则/EDX/业务 Acceptance，详见交付包 review-again.md。

## Journey 的真实验证

**J01**：复用 B02 composer/Thread/ArtifactsDrawer、B05 Conversation/Turn、B07 reader。缺附件正文消费、不可变版本、反馈和持久回读。证明：独立 marker 资料→实际响应采用→开 v1→引用修改→v2→验证→Native 重开字节和摘要一致；读取/保存/验证失败分别保留输入及旧结果。

**J02**：复用 B02 roster/Topic actions、B08 Search/opener。缺生产标签及跨角色索引的真实授权/定位证明。证明：两个角色及两身份；搜索标题/正文/产物/标签，定位确切消息/版本；改名/置顶/标签增改移除重开一致，标签不控制执行；头部搜索展开/关闭保持位置与焦点；未授权标题、片段、数量和通知均不泄漏。

**J03**：复用 B05 队列、取消、重放和版本控制，以及 B02 ask/approval UI。缺完整宿主 steer 和真实控制投影。证明：真实延迟执行→排队→取消→admission 不发生；旧审批/并发回答/Stop 竞争、副作用恰一次，断连先核对；原型 busy 返回不能计队列完成。

**J04**：复用 B06 文件动作、B07 text/pdf/office/image/media reader。缺版本授权输入、选区/DOM 批注和反馈接线。证明：逐声明格式实际字节→对应版本→引用/批注→新版本→下载摘要一致；损坏/不支持降级，撤权及切任务立即 abort，不能下载错误最新版。

**J05**：复用已建 MCP 发现/执行及成熟 browser host。缺任务归属、身份、租约与 Portal 控制消费。证明：受控网页真实导航/读/点击/填表/回读；接管期间 Agent 无操作，归还重新观察；另账号/任务 Cookie 隔离，断连及跳错页面可恢复。

**J06**：复用 B10 external session、进程及已有 terminal 表现；共享 reader 消费结果。缺 stdout/stderr/exit、stdin、实际 Diff、检查版本绑定。证明：隔离目录真实修改→Git/文件 Diff 一致→检查故意失败→修改→复测→产物回读；终止/保留、冲突、重开、未经授权提交为零。

**J07**：复用已有 branch/session resume。缺授权截点、资源继承、旁聊读范围及独立环境绑定。证明：主任务和 fork 独立输入/审批/文件/结果；旁聊无主资源写入，结论显式进入草稿；无法隔离时在承诺独立编辑前说明。

**J08**：复用 B03 身份/SOUL/AGENTS/extensions、B04 模型、B05 当前角色。缺规则版本消费、能力可用性和停用后历史保留。证明：旧轮运行中编辑→旧轮仍原规则→新轮用新规则→工具真实执行；保存失败保留输入，撤权阻断执行，停用后历史可读。

**J09**：复用 B09 原 Memory CRUD/search/snapshot/prompt assembly。缺候选确认治理、中文质量、来源失效及新轮版本投影。证明：独立偏好→候选→确认→改写新任务召回→定位真实 source→纠错→新轮行为改变→删除/撤权→再轮无消费；负例临时要求不成为长期记忆。

**J10**：复用 Dashboard 已有模型配置/连接/用户授权，B04 客户端选择和 B10 runtime。缺各 CLI 完整登录与恢复入口返回。证明：同身份安装→连接→授权→选模型→真实回答；第二身份拒绝；撤权/过期/重连/执行器重启独立测试，原 task/draft 返回，未知副作用不重放。

C07/C16 的 deferred 不计完成。C06/08/09 一旦广告就必须跑 J05/J06。C15/C17 在明确降级范围内验证；C01–05/C10–14/C18 必需链条不得以原型缺失为由延后。

Formal Acceptance 由业务 Owner 注册有效 Journey/Environment/Fixture 后运行 canonical validator，不能把上述名字硬填进不支持的 runner。测试结果、检查记录、产物版本、实际来源与当前源码身份必须绑定；旧失效 E2E Gate 与不存在的 Memory 路径不能提供依据。

原型证明分开：本机有界观察及其当前源码绑定范围见 prototype/README.md 指向的证据包，不按观察组数推导120实例全部通过。J02 的总览下一步、活动排序、上下文搜索与 J04 的成果/版本选择、精确来源回读、阅读版本导出需逐路径记录；来源缺失必须阻断跳转。L1–L4 终态 cells、独立 Experience receipt/admission 和 Native 生产证明保持未完成。TypeScript/build/source validation 通过不改变产品判定。

当前候选的定向回归补充：

- J02/J07：新任务无空工作面；顶部呈现已打开实例，“+”按需打开；关闭查看、固定锚点收起与结束资源分别验证。来源下钻具名返回，普通切换无后退历史；编辑草稿、对象集合与开合刷新保留。
- J03/J08：目录安装→Profile 绑定→命令使用同一来源；停用后保留原指令且不产生新成果；恢复后显式重发。失败导入保留输入，成功导入可在 Profile 回读。配置格式有效不等于连接有效。
- J04/J05：网页读取保存 URL 与正文，后续结果消费该来源；来源链接与原字节可回读；制作网页绑定所选正文，下载字节与阅读版本一致。场景中的读取不证明联网执行。
- J08：Meeting digest 采用本轮有效资料与绑定快照；多个行动项不得因同字段名互相覆盖；不支持的命令不得静默降级成普通生成。
- J05：从任务调用打开同一网页→必要时接管→登录→归还重新观察→读取并生成文档；未登录继续等待，停用阻断后续动作，连接失败保留恢复入口。结束浏览不影响其他任务，关闭面板不结束浏览。此场景路径不证明真实 Browser/控制租约/网站登录。
- J06：文件变更→持续进程→服务网页→窄屏问题反馈→修订→复测。原型页面确实消费修订前后的宽度值；状态检查只作场景反馈，不充当真实项目测试。
