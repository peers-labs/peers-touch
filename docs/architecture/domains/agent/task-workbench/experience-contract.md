# 持续任务能力 — 体验合同

状态：accepted（Owner 2026-11-02 确认；生产证据按执行计划切片回填）。TW-20261101。源自现有 Agent/Topic/Turn 和逐功能审查。

## 信息与动作

Shell 只负责导航、Search 覆盖层、通知和 Settings。Agent surface 的主对象是当前任务；roster 提供角色上下文，任务区提供跨角色任务列表，对话区承接当前任务的连续交流，工作面承接任务中的阅读对象。全部任务是列表的汇总视图，不新增一级菜单或状态 Owner。

任务新建只使用现有 composer；结果引用、网页选区、HTML 批注和 Diff 评论回到当前任务草稿。输入、附件和引用按任务保留，任务成果始终在同一任务中可回读。网页预览/文件/Diff 是由实际对象驱动的工作面；未连接的外部能力不提供虚假的成功入口。运行状态来自执行回执，列表/消息/工作面/通知使用同一含义。

桌面默认并排展示任务、对话与工作区。工作区顶行显示已打开的对象实例，复用同一资源时定位原标签；标签行“+”只打开文件、浏览器、终端或旁聊。关闭标签只关闭查看；任务标题旁的“⋯”管理任务目标、重命名、固定、派生、标签和删除；右上固定锚点收起/恢复整个工作区，放大只改变布局。文档、网页、进程和代码变更各有对象操作，Profile 返回保留工作现场。详细空间合同见 [工作区提案](./workspace-experience-proposal.md)。

任务标题区承接当前角色、执行位置和轮数；收起/展开入口保持同一锚点。同一目标继续在当前对话中表达，独立目标才新建任务。窄屏以文字切换“对话／工作区”，恢复时保留草稿及阅读对象。

本轮进度并入标题信息行。对象标签负责选择与关闭查看，文档操作行左侧选择版本，右侧使用带文字的“编辑、反馈、更多”。核验结果和“接受此版本”归正文底部的审阅区域。网页历史只放在地址栏；具名返回只用于来源下钻。跟随仅作用当前任务，手动选标签或编辑立即退出；后台结果只提示，不切换阅读或焦点。

概览只展示当前目标，不重复任务标题；资料、过程与成果数量回到各自分组。新任务和无成果的阅读面用紧凑说明提示下一步，不占用大块居中展示区；输入仍固定在对话底部。笔记不重复工作面名称，输入与保存在同一行。Agent 列表仅在存在多组时显示分组标题，收起侧栏不保留不可见标题占位。

资料更新后，下一轮和继续轮使用同一当前资料投影，而不是回到首次附件；用户可在文件工作面排除或恢复后续采用。阅读中的正文草稿按版本保留，返回同一任务恢复编辑；保存为新版本只清除已保存的草稿。保存的旁聊笔记和未提交输入刷新后仍存在；放弃草稿、删除笔记分别需要明确动作。

终端按需打开持续进程，显示输入、输出和退出状态；关闭查看不终止进程，结束进程是独立操作。服务链接打开绑定的浏览器，服务退出后浏览器给出返回终端的恢复动作。代码变更绑定文件前后内容与检查修订，反馈、修订与复测在原任务完成。旁聊结论显式采纳，不证明并发模型能力。派生 HTML 预览与浏览器会话分属不同资源。

接受属于确切成果版本，保存接受时间与检查快照。正文和网页各自接受，不覆盖其他成果记录；历史记录保留，新版本不能继承。列表仅在每项当前成果均有匹配当前目标、条件、资料修订和字节的接受记录时显示“成果已接受”，不据此宣布任务完成。目标/条件/资料改变或网页来源正文不再是当前版本，使旧记录不再有效，重新检查本身不能恢复旧接受。总览“审阅成果”打开首个尚未有效接受的当前成果，正文接受后直接承接网页审阅。

派生动作明确继承已完成历史、资料和已保存笔记；不继承未提交输入、编辑草稿、队列、审批、检查与接受。新任务为消息、资料和成果生成新 ID，一次性重绑网页正文来源、消息反馈和笔记引用。来源缺失不回退其他正文。修改派生成果不得改变原任务；此独立性限于本机原型对象，不承诺外部文件隔离。

目标与接收条件在任务概览显式编辑，变更记录保留原目标/条件/约束，当前检查与接受依据立即失效。下一轮冻结该任务的目标、资料修订、Profile 与已确认记忆；概览显示本轮资料、生成/修订成果、审阅接受的进度，不作为任务规划或自动完成判定。仅接受本轮产出的成果才结束其审阅步骤。对话显示简短回执和对象卡片，正文在工作面阅读，不重复铺满两栏。发回反馈同时保留输入引用和新成果的前版关系。

不同任务可各有一个活动轮，同一任务的后续输入按序排队。停止只作用于指定任务并暂停其队列；其他任务仍运行。后台队列读取所属角色、模型与任务约束，不切换当前任务、工作面或输入焦点，也不清除当前草稿。审批只记录当前 request 的决定，结果由其后续回执表达；批准文字不冒称工具完成。

网页反馈读取隔离 iframe 的实际 DOM 选区，保留 HTML 成果 ID、版本和所选文字，再进入同一 composer；脚本不运行。旁聊笔记可以在尚无成果时采纳为主草稿；存在成果时保存来源版本，采纳只带入草稿，显式发送后才执行。当前原型的网页改写仅支持明确文本替换；任意布局推理或 HTML 节点定位锚点仍未证明。

继续/新建/fork 的目标边界和完成权限消费 [产品定义](./product-definition.md)；停止、队列、标签、删除、撤权及迟到结果消费 [状态模型](./product-state-model.md)。逐操作输入、接收断言与反向校验只在 [验收矩阵](./acceptance-matrix.md) 展开；下列 Journey 组织操作顺序，不另定义终态。

列表各自使用一个38px头部，Agent 的名称、搜索、新建并排，任务的全部任务/标签范围、搜索、新建并排。点击搜索时原位换成满宽输入和关闭；不插入搜索专用行，不陈列固定状态 Tab。关闭恢复焦点和头部，不下移列表。无内容的 Agent 分组标题不显示。Agent 行“⋯”只提供 Agent Profile 管理入口，不重复列出能力和记忆；进入 Profile 后切换对应 section，返回保留任务草稿和工作面。

标题介绍当前任务一次；角色名称解释上下文，不能在全局导航、内部页签和页面标题重复占同一层级。高频主操作是发送/排队或当前阻塞决定；工具回执和版本选择为次级动作，Tab 只切阅读范围，不直接执行命令。永久删除显示文字、影响范围和确认。

## 完整旅程

**J01 资料交付与改稿（C01/02/04/05/10/11/14/18）。** 从 Agent 新建任务并选择可用模型，附独立资料并输入目标；读取失败保留资料与草稿。发送后得到对应 Turn 接受回执，执行按真实资料产出版本 v1。消息点击产物打开 Portal 正文，选实际段落→引用进同一草稿→填写修改→显式发送。新 Turn 产生 v2，用户检查后运行验证；失败保持 v1/v2 和反馈，修订后复测。通过后重开同一任务、版本及验证依据。未被读取的附件不允许显示为“已采用”。

**J02 寻找与管理（C01/02/15/18）。** Agent 内已有列表用自定义标签选择范围，头部搜索展开后输入标题、对话或标签；全局 Search 输入标题、正文、资料标签并重新授权。命中打开所属 Agent/Topic、消息或版本位置。改名/置顶/标签同步到消费者，重开回读。改标签不启动、停止或清空队列，取消编辑保持旧值；删除标签不会删除任务或结果。永久任务删除另行确认，停用角色不隐式删除任务。

**J03 运行控制（C03/10/18）。** 持续运行时下一轮输入由现有队列接受，展示位置、内容和取消回执。当前轮补充仅对支持 steer 的宿主提供；不支持解释并保留下一轮输入。审批显示真实影响，批准/回答只释放对应有效 request，拒绝保持未执行并等待替代决定；旧决定不可影响新轮。Stop 回读取消及已发生副作用，默认暂停后续队列；取消全队列另作明确选择。断连显示最后确认状态，未知结果先核对再重试。

**J04 阅读、版本与反馈（C05/09/11/17/18）。** 从消息、Search、附件或工作进度打开同一任务对象。reader 读取获授权版本字节，按格式预览；损坏/不支持可外部打开或重取同一版本。选择版本→读正文→选区/HTML 节点批注→送回当前草稿→显式修改→新版本→再读。导出就是正在阅读的版本。撤权立即阻断新读和未来消费；旧引用保留安全来源说明，不复制敏感内容。

**J05 浏览器操作（C06/11/14/18）。** 当前任务申请可用 Browser 能力，明确账号和操作范围→导航→读取→点击/填表→读回。网页引用送回本任务。需要登录时转交控制租约并停止 Agent 操作；归还后重新观察页面与身份再继续。跳错页面、网络失败、账号切换或 task mismatch 必须停在可恢复状态；浏览器模拟页面不计真实 E2E。

**J06 代码与进程验证（C04/08/09/10/18）。** 明确任务隔离环境及权限→真实文件修改→检查实际前后版本 Diff→命令执行→stdout/stderr/exit 回读。检查失败绑定当前版本→用户反馈→再改→复测→打开文件和验证日志。长进程有输入、终止/保留和存活回执；冲突/回滚另作决定，不把 fork 当文件回滚。提交和发布分别授权。

**J07 延续、旁聊与分叉（C02/03/04/11/18）。** 打开旧任务先回读，再由执行器 resume 恢复；不可恢复则保留历史并明确新运行。旁聊只读授权截点，结论显式送回主草稿；fork 选择历史与资料继承，并说明独立写环境能否提供。没有隔离环境不允许承诺独立编辑。源任务与 fork 的输入、文件、审批、结果不串用，断连/删除各按作用域处理。

**J08 角色配置到消费（C11/12/13/14/18）。** 由 roster 打开既有 Profile，编辑身份、独立 SOUL/AGENTS、extensions；失败保留编辑，Back 回原任务。新轮显示采用的新规则版本，运行轮仍是原版本；工具绑定→命令发现→授权→执行→结果回任务。撤权不只是菜单隐藏，执行也必须阻断。角色停用保留历史、暂停队列并回读当前轮停止；继续旧任务先显式选择可用角色及核对权限，不自动换角色。永久历史删除单独确认。

**J09 Memory 质量（C11/12/13/18）。** 当前输入中的长期偏好提取为来源明确的候选→选择范围→确认或拒绝。确认条目由已有 Memory Owner 提供给第二个中文改写任务，行为与采用来源一致。打开 source session/turn→纠错→新轮读新版本；删除/来源撤权→索引和上下文失效→再任务不消费。来源不可读时不泄漏内容，不回退无关快照冒称召回成功。

**J10 模型与授权恢复（C03/04/14/15/18）。** Dashboard 配置/安装→供应商连接→分配当前用户→Desktop 模型可用→选中→真实回复。失效时在原 composer 附近说明缺失对象，草稿保留；恢复进入全局模型消费页和 Dashboard 对应管理位置。恢复后带原 task/return target 回读授权，再显式继续；未知结果先核对，不能重放已执行外部操作。

## 保存、返回与工艺

任务总览是现有列表的阅读范围，不新增一级入口或状态分类 Tab。它按最近对话活动排序，固定任务仍在前；状态来自同一任务，下一步按批准、回答、恢复、审阅或继续工作表达。总览行打开待处理对话或最新正文，保留该任务草稿；资料和成果数量只作辅助信息。搜索同时覆盖目标、条件和约束，避免任务改名后无法按真实工作内容找回。

工作面顶部可选择本任务成果，文档操作行选择该成果版本。网页预览可选择页面版本、下载正在看的字节，并回到绑定的正文来源版本。查看来源或比较版本属于下钻：显示“返回〈来源对象名称〉”。切换独立工作对象不增加返回历史。缺失来源不得回退成其他正文。

所有浮层/外部管理跳转保存 task、draft、版本、选区及返回目标。Esc 取消局部动作，关闭 reader 回原产物/命中按钮，失败恢复回原输入。换身份清空未授权投影，旧 draft 不自动发送。

工作面由对象驱动：空任务不展示空文档/网页/差异页；“+”按需打开工作对象。workspace.tabs 保存查看集合及各自的来源返回点，activeTabId 指定当前查看，开合、布局、跟随、滚动与正文草稿归任务保存。浏览器和进程资源归 Thread，组件卸载不终止执行。外部打开请求消费后清除，任务切换不能重放它。

扩展目录、角色绑定、当前轮消费分属原 Owner：全局 Settings 持有安装/配置/可用状态，Profile 持有角色引用，轮次准入重新读取当前可用性并保存采用快照。停用保留引用；恢复不自动重发。仅通过配置格式检查不能显示连接成功，未知能力不能退回通用文本并声称执行成功。原型以 Meeting digest 的原文行动项抽取展示该闭环，不把此样本外推为任意 Skill/MCP 已实现。

使用工具的入口位于 composer 的“工具”按钮；管理入口复用 Profile。有绑定但没有执行流程的条目禁用并说明。浏览会话绑定任务与调用，支持 Agent 操作、等待接管、人工控制、重新观察、读取完成、错误、结束及断连。归还后检查页面与登录状态，未登录继续等待；正常读取保存来源并产生文档。原型由场景状态驱动这些转换，不连接真实账号或网络，也不要求用户粘贴正文代替 Agent 读取。

来源可由文件、显式对话资料或浏览器读取提供。网页保存地址与内容快照，后续采用当前修订；来源不可用或用户排除后不得继续作为本轮事实。引用对象及版本必须在 composer 可见、可取消；制作预览等对象操作不得暗中消费未发送草稿。

复用 shared UI Identity、Agent module、PrototypeAgentAvatar、PanelToggleDock 和既有 component stack。采用 Quiet Protocol Minimalism；signature 是同一任务的过程、可读结果和反馈连续关系，不靠新卡片网格或装饰动效表达能力。

正向校准：现有 Profile 返回保留草稿、独立规则、产物真实正文、审批范围和 reader focus。负向校准：重复一级入口、toast 代替对象定位、能力开关无人消费、静态 Diff/HTML、任意命令固定成功、固定 Memory 来源、“通过”按钮代替验证。

L1 覆盖完整 trace；L2 必看关键状态、宽窄、长内容和声明主题；L3 以独立输入验证消费者和失败；L4 包含 focus、语义、触摸、对比度、静置和长内容。当前有界交互线框观察资料、版本、队列、规则与记忆消费，详见prototype入口；未支持状态按明确cell留缺口，不推广为完整终态。

## Experience Design 边界

当前结构化case和findings保存在工作区 `.local/deliverables/function-design-skill-20261101/bounded-wireflow/`；既有历史包不覆盖。10条路径预算分别绑定其Journey，仍是有界草拟模型；恢复保留原task/draft/resource/version，不能用总分掩盖任一成本超标。

canonical source/schema/evaluator 有效只说明闭合模型可以被评审。当前按用户“继续原型、终品效果确认后才落地”的要求制作可操作体验候选；Product acceptance、独立 Wireflow receipt 与 Reasoning admission 仍未成立，不能将候选提升为正式高保真准入、pending-review、confirmed 或生产依据。已有 baseline 截图不替代这些门。

原10路径 case 是先前有界输入，未覆盖本候选全部原子操作；目标、队列决定和完成条件变化后须由原 Prototype/EDX Owner 重绑对应 trace 和 cells。旧 receipt/findings 不修改为本次通过，也不从旧 schema 有效推导新操作已经受审。
