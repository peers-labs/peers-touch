# CLI 账号连接：可见状态草案

状态：draft。安装状态、账号状态、模型调用状态是三个独立事实。

- 未安装：安装动作由管理员拥有；登录入口说明须先安装。
- 未连接：显示“登录 X”；支持 key 时显示“获取密钥”和输入方式。
- 正在准备：立即反馈，允许取消，不可重复创建任务。
- 等待供应商授权：显示可直接打开的地址；按方式展示设备码或回传码输入。
- 正在检查登录：不再接收回传码；仍不声明模型调用成功。
- 已登录：显示重新连接、断开连接和调用检查。
- 连接已失效：保留已选模型，提供重新连接，后续分发拒绝。
- 登录失败：保留原服务商和仍有效的旧连接，提供本地重试。
- 登录已取消：回到原详情，保留旧连接，清除本次等待。
- 授权已过期：旧地址和设备码不可继续使用，直接“重新登录”。
- 当前版本不支持：明确原因和精确升级或支持方式入口，禁止开始登录。

重登录失败不等于旧连接失效；当前版本不支持不等于尚未安装。
调用测试的等待、成功和失败独立于上述账号状态。
所有状态与恢复路径由 acceptance-matrix.md 的用户断言验证。
