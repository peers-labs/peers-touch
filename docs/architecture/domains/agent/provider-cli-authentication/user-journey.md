# 模型服务使用流程候选

状态：draft。描述目标体验；现有产品尚未实现整条流程。

管理员打开 Dashboard → 模型服务，选择“添加模型服务”。

选择 CLI 服务时，先点击安装，完成后同一行显示“连接账号”。
点击连接，在自己浏览器的供应商授权页完成授权，返回原详情查看连接结果。
选择 API 服务时，填写地址与密钥，保存后检查连接。
登录失败留在本服务，点击重试；取消或离开不会丢失已经保存的配置。

连接成功后查看模型。厂商不能列举型号时，页面说明使用厂商默认选择。
选择模型点击“验证调用”，看到短请求结果；验证可能产生供应商用量。
验证成功后选择用户或用户组，点击“分配模型”。
完成页直接显示谁获得了哪些模型，并提供按其权限试用的入口。

普通用户打开 Desktop → 全局设置 → AI → 我的模型。
管理员分配的可用模型在这里出现。选为个人默认后进入 Agent 发起对话。
用户无需再次输入共享账号密钥，也无需运行 CLI。

管理员没有分配模型时，页面明确说明需要管理员分配。
共享账号过期时，由管理员在原服务重新连接。
模型被撤权或失效时，默认偏好仍可见，但发送暂停；用户主动选择其他模型。
网络失败和模型调用失败保留输入，可以重试。

管理员开启个人连接策略后，用户可以在“我的模型”连接自己的供应商账号。
此连接只供本人使用；本人重新连接或断开不会影响共享账号。

管理员修改配置或凭据后重新验证受影响模型，再恢复可用状态。
撤销 Alice 的模型权限只影响 Alice；断开共享账号则影响依赖它的所有用户。
卸载 CLI 前显示这些影响，用户确认后回收相关任务与运行材料。
