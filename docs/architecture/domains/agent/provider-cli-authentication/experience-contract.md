# CLI 账号连接：交互合同草案

状态：draft。受 product-definition.md 的 PCA 能力与 Journey 约束。

选中服务商后，连接区直接显示一个主要动作。TRAE 的默认动作是版本匹配的
“登录 TRAE”；支持 key 的 adapter 显示次要“使用 API key”动作。
供应商不支持的方式不呈现可点击的虚假选项。

授权区在原详情页内展开，保留服务商选择和配置表单。设备授权展示地址、
设备码、复制动作、有效期和取消；回传授权只显示供应商需要的一项输入。
不展示通用终端、完整进程输出、token 或文件路径。

供应商授权页在用户浏览器的新标签打开，原页继续等待结果。原页一直保留
“打开授权页面”；浏览器拦截弹窗时用户可以再次点击。刷新原页恢复未过期的
授权任务；其他账号不能恢复它。切换服务商不把旧任务绑定给新服务商。

离开后返回同一服务商可继续等待；账号退出、权限撤回或显式取消则结束任务。
失败说明对象和下一步，例如“登录请求未发出，请重试”，不显示空体 500 或
让用户自行执行 `/login`。

鉴权检查只证明账号连接，调用检查只证明选择的模型在当次请求成功。
“已安装”“已登录”“模型调用成功”分别表达，不合并为一个 ready 标签。

焦点进入授权区标题，取消后回到登录按钮，完成后回到连接状态。状态更新使用
可访问的 live region；设备码可用键盘复制，回传码有明确 label。中英文扩展、
窄屏、暗色和减少动效均需真实界面检查。

原型须复用项目 Prototype Lib、现有 Settings shell 和 Dashboard Ant Design
组件。没有确认的原型或真实 UI 证据，不能声称本交互已完成。
