# Search 产品合同

> **Status**: draft
> **Created**: 2026-10-22
> **Owner**: Search Product / Client
> 本文所有目标行为均为建议，待确认；现有能力事实见研究文档。没有已测产品指标。

## 1. 产品论点与完成条件

Search 是用户主动唤起的 **Peers-Touch 域内**统一检索入口：只覆盖端与 Station 持有的 Peers 业务对象，且只返回当前账号当前有权限读取的内容。用户记得一个人、一段话、一个附件、一项功能或一个问题时，应能用同一个搜索框找到可识别、可打开、权限正确的对象，并知道本轮检索范围。

产品能力包括传统关键词检索、域内附件名称/正文检索、功能直达，以及 AI 对查询理解、语义召回、排序和有来源回答的增强。人员、消息、Social、Agent/知识、域内附件、Applet 贡献对象和功能是来源/对象；AI 是贯穿检索的能力与主动回答意图。用户不必先判断该选哪一种检索技术。

**范围边界（用户决策，2026-10-22）**：检索宇宙封闭在 Peers-Touch 域内。不提供公网网页搜索，不索引用户 OS 上 Peers 之外的目录/文件，不接入外部网站/SaaS connector，不存在“跨用户搜全部数据”的管理员视角。Peers 自己管理的附件（聊天附件、知识文档等）属于域内对象，与 OS 任意文件严格区分；功能直达是域内导航，不是外部内容。Federation 仅在现有联邦授权上下文内按需查询对端可见对象，不抓取、不整站索引。

**用户输入**：仅 Peers 域内内容、AI 智能搜索与功能搜索；体验现代且克制；普通启动默认显示 Chat，点击 Search 才显示搜索首屏。**产品建议**：采用负一屏的快速触达与轻量结构，保持完整结果与深入检索能力；具体布局和快捷键待原型确认。

主要用户为 Peers 当前账号的使用者；完整任务从全局入口或模块内线索开始，以打开正确对象、看到命中上下文并能继续原任务结束。问答任务以得到有可验证引用的答案或明确的证据不足反馈结束。Search 不是内容列表终点。

产品提供四种连续意图：

- **找**：名称、片段、作者、时间、类型、位置或完整地址找对象。
- **打开**：最近访问、精确名称与地址快速进入原对象。
- **探索**：当前授权的人员、公开内容、Applet 与来源范围；与关键词结果明确区分。
- **问**：用户主动提出问题，以本轮允许的来源为证据，返回引用。

命令动作可以从 Search 转入原模块，但发送、关注、删除、分享、安装等不得仅因输入或 Enter 搜索而发生。

## 2. 入口与信息架构

### S-01 按需搜索与默认落点

普通启动、登录完成和切换账号后默认进入 Chat tab；本合同中的 Chat 指 Shell 的人际聊天页，与 Agent 页分开。没有选中会话时呈现 Chat 自己的列表/空态，不自动打开其他模块。明确打开某个对象的深链由原对象导航合同处理。

Search 保持全局可达的按钮；点击后显示搜索首屏，返回恢复触发前的页面和上下文。搜索首屏不作为启动兜底，不因会话空、来源配置缺失或上次停在 Search 而自动出现。Search 在同一使用会话内保留查询，不借跨启动恢复抢占 Chat 默认落点。

首屏结构为主搜索框、少量最近打开对象/固定入口和紧凑的范围选择。借鉴手机负一屏的一步触达和低阅读负担；不引入无限资讯流、热榜、自动 AI 长回答或模块卡片墙。首屏是否存在最近记录遵循 S-15 的个人控制。

内容深度在查询后展开：即时建议、综合结果、来源筛选与按需预览。Search 的重要性由可达性、覆盖与完成任务的可靠性体现，不要求它成为默认首页。

### S-02 全局快捷搜索

Search 按钮是主入口；建议额外提供 ⌘/Ctrl+K 作为等价的主动唤起方式，具体绑定由 Shell 总表和原型确认。快捷搜索呈现紧凑 Overlay，完整检索使用 Search 页，两者共享状态。输入时先显示本机可用的精确对象/建议；Enter 打开已选对象，未选对象时提交当前范围查询。Escape 关闭 Overlay 并把焦点还给触发点。

快捷框与完整页共享同一查询意图、范围、选中对象及返回路径，不维护两套结果。模块不得各自抢占全局快捷键。

输入建议只来自本机与本站域内来源，不把尚未提交的文字逐字发送给任何外部模型；未提交前不产生外发请求。

### S-03 局部搜索

会话内、人员页、Notebook 或 Applet 内的搜索带可见位置约束。用户可一键扩展到全部允许内容，同时保留原条件。清除位置条件须显式可见，不能悄悄扩大隐私或远程范围。

Mobile 复用 Chat 默认落点与 Search 按钮按需唤起的语义；完整结果单列，筛选用 Sheet、预览进入详情再返回。搜索按钮的具体全局位置与现有导航协调后通过原型确认，不先引入整套负一屏 Feed。

## 3. 哪些内容进入 Search

来源可用和内容可读是两件事；安装模块或加入来源不会自动给用户更多阅读权限。

### S-04 人员与会话

可检索已知联系人显示名、handle、必要身份字段；显示关系和来源。当前联邦目录与熟悉联系人可区分。完整远程 handle 进入“解析此地址”意图，仅在已建立的联邦上下文内解析，目标站对当前 actor 不可见则不暴露其存在。

会话对象可检索用户可见的名称、参与者和必要元数据。命中后打开正确 Direct/Group 会话。隐藏、移除或无权访问的会话不得通过标题或建议暴露。

### S-05 人际消息与私密 Social

检索本机已取得并可读取的内容。结果显示作者、时间、会话/帖子位置、命中片段；消息打开到原 message/thread anchor，私密评论打开父帖及评论。

消息编辑后使用当前可见正文；撤回、删除、个人隐藏与治理限制按原域规则生效。加入新设备且历史未恢复时显示“仅搜索已恢复内容”，提供原恢复流程入口；不能回退到服务器搜索私密正文。

### S-06 Social 内容

公开帖子、评论、标签可在当前已允许来源内检索。评论继承父帖的可见性；同名对象显示作者和来源，不能仅据标题合并。公开发布与允许被目录发现是不同产品权限，建议显式区分。

Federation 结果表示已建立联邦上下文中的授权覆盖，不承诺全联邦可见，也不批量索引对端内容。源站内容不可达或对当前 actor 不可见时提供不泄漏存在性的反馈。

### S-07 Agent 与知识对象

可检索当前 actor 有权访问的 Agent、会话/topic、用户与助手消息、笔记/知识文档、任务/产物。工具输出、内部推理、凭据、Secret、原始执行日志不默认进入索引。业务模块须定义具体可搜字段。

Agent conversation 与 human conversation 在结果上能辨认。Notebook、附件正文/OCR 等只有其模块已声明并完成处理时才显示为“可搜正文”；只搜名称时需如实标注覆盖。

### S-08 功能直达与 Applet

Applet 可搜安装/可访问目录的名称、用途、公开能力；Applet 内部对象由其接入声明和当前授权决定。卸载后不保留可打开的伪对象。

功能检索覆盖 Settings、模块与 Applet 已声明的入口、常用别名、用途和帮助，例如“换模型”“添加好友”“设置消息提醒”。结果能说明并定位真实入口；具备创建/发送等副作用的操作必须打开原模块的表单或操作面，再按原合同执行。输入“发消息给张三”不能直接发送。

功能结果不要求用户知道内部菜单名称；支持别名与自然语言匹配。只展示当前账号能用的入口，平台不支持或尚未安装的能力具有明确状态；不得把不可调用的占位动作显示为可用功能。功能描述可搜，token、密码、Secret 或当前凭据值不可搜。

### S-16 域内附件与文档

检索对象限定为 Peers 平台自己管理的附件与文档：聊天/会话附件、知识/笔记文档、Agent 任务产物、Social 附件等。它们随所属父对象继承同一套 actor 可见性；父对象不可读时，附件名称、正文、缩略图与计数都不可见。

附件名称、类型、所属对象与时间是基础检索内容；所属模块已完成正文提取的格式可进一步提供正文、文档页/段落命中及语义检索。未完成提取时显示“仅名称可搜”或“正文处理中”；加密、损坏、不支持的格式显示真实边界，不能伪造正文覆盖。设备私有附件的正文与向量只在本机受保护索引中存在。

附件结果显示名称、类型、归属会话/文档、时间与命中片段；同名对象可辨认。主动作在原对象上下文中预览或打开；已失权、已撤回、被删除或历史未恢复时有区别明确的反馈。

### S-17 明确非目标：公网、OS 文件与外部连接

以下不是 Search 能力，也不出现在范围切换、设置或来源状态中：

- 公网网页/搜索引擎检索，以及任何把查询文字发送给外部搜索商的路径；
- Peers 之外的 OS 用户目录、磁盘文件与系统索引；
- 外部网站订阅、SaaS/connector 抓取与第三方资料库索引；
- 跨 actor 的全局检索、为管理/审计目的检索他人私密内容。

用户在聊天或帖子中收到的外部链接按普通消息内容（文字/URL）参与该消息既有的域内检索；Search 不抓取链接目标，也不把链接目标网页纳入索引。未来若产品重新引入任一外部来源，必须作为新的范围决策重走产品与架构确认，不能以配置开关或 Applet 形式悄悄恢复。

## 4. 查询、筛选与结果

### S-09 线索表达

支持普通词、短语、完整 handle/对象 URL、类型、作者、位置、时间和来源约束。中文、英文、混合文本、编号与人名是必要评估集；不预先承诺拼音或语义召回已实现。

建议提供 `type:`、`from:`、`in:`、`before:`、`after:`、`source:` 等编辑捷径；展示为可移除筛选 chip。自然语言转条件后显示解释，例如“张三上周在项目群发的附件”对应作者/时间/会话/附件，用户可改，不静默重写问题。

组合中某来源不支持一个条件时，显示范围限制并允许移除条件；不能忽略过滤器后返回更宽的结果。空查询只能用于最近/探索或已经足够明确的筛选，不触发任意正文扫描。

### S-10 结果组织

建议完整结果页以“综合、功能”作为紧凑的用户意图切换，具体标签通过原型确认；综合中按人员、会话/消息、Social、文档/附件、Agent、Applet 等域内类型筛选。不存在“网络”“本机目录文件”切换；所有范围选择只在当前 actor 可读的域内对象集合内收窄。

综合只融合当前 actor 本轮允许范围。确定的对象名称与功能直达保持容易找到；功能动作、附件与会话消息用统一行结构与必要的类型差异展示，不展示任何域外来源。

精确身份/标题可放在顶部快速打开区，其余为稳定的混合列表，支持切入类型内排序、时间筛选与分页。用户选择“最近”时排序必须按可解释时间语义；正文相关性不能直接由单个来源的返回顺序决定。

每条结果最低展示：标题或正文线索、类型、作者/归属、所在对象/来源、相关时间、可见片段与打开动作。附件显示真实处理状态，不使用外链样式伪装域内对象。Desktop 可展开右侧预览，Mobile 用详情路径；预览保持选中，不改变搜索范围。

键盘上下选择、Enter 打开、复制链接、返回保留 query/filter/scroll；操作由可访问的真实控件承担。来源加载完成后不会把焦点或已选结果突然移走。

### S-11 覆盖与分页

“没有结果”仅指所选可搜索范围成功完成而无命中。否则显示“部分来源暂不可用”“历史尚未恢复”“来源正在收录”等可行动状态。

数量只表达有权可见的已知命中。完整数字、估计值、当前加载条数必须有不同语义；未知不显示 0。分页保留筛选与排序，新增结果不重复，也不因某来源慢而无提示消失。

### S-18 重复使用、缓存与刷新

Search 应复用已经取得且仍可读取的数据。以下是目标交互和读取约束，不是已测
性能；“有效命中”要求内容版本/新鲜度和当前读权同时有效，且没有收到失效事件。

- **反复找同一功能**：多次输入“设置”“换模型”，匹配同一版本的本机功能目录，
  不重复加载目录、不调用模型；安装、入口或账号可用性变化后更新相应部分。
- **输入、退格、再输入**：IME composition 不提交查询；本机建议有界调度。
  相同规范条件的有效结果直接复用，来源 query 和正文读取均为零次；相近词只
  复用已取得的对象投影，不能过滤上次截断结果来冒充新词的完整查询。未提交
  输入继续遵守 S-02 的外发边界。
- **打开对象再返回、关闭后重开**：同账号同范围、使用会话内恢复输入、筛选、
  已加载页、选中对象和滚动位置。有效命中不重查来源或重读正文；恢复状态
  不要求页面一直挂载，不开启搜索词持久历史，也不改变启动进入 Chat 的规则。
- **选择与预览**：上下选择或鼠标移经结果不逐条请求详情。只有用户请求的
  预览按需补齐字段；同一对象和投影版本的有效预览直接复用，尚缺字段才读取。
  打开原对象可复用正文与定位绑定，原模块保留打开时的最终读权判断。
- **翻页和回滚**：已经加载的有效页直接恢复，只为未加载页使用 continuation；
  普通翻页不重取第一页或已加载正文。游标到期保留可读的已加载页与输入，
  说明需要重新查询后才能继续。
- **新消息、编辑、删除与撤权**：新内容提示“有更新”，不突然改动已选结果
  或滚动位置；编辑更新受影响投影。已删除、隐藏或失权对象立即退出结果、
  预览和引用，计数/覆盖无法确认时降为未知，不等待用户刷新。
- **明确刷新**：主动检验本轮内容是否更新，必要时重查受影响来源并重新排序；
  未变化的目录、正文不全量重读。刷新失败保留仍获准读取的结果，标明过期或
  部分失败；一次失败不改写为“没有结果”。
- **弱网与离线**：优先恢复允许离线读取的本机已同步内容；来源状态与覆盖时间
  可见。仅内容过期且读权仍有效时，可先显示并后台更新；私密读权未知、租约
  到期或已撤销时停止显示，不能用旧正文填充结果。已经展示的结果也在到期
  时主动遮蔽，不等再次搜索；设备唤醒/页面恢复先判断读权再显示。
- **锁定、退出与账号/站点切换**：立即遮蔽对应私密结果、预览、建议和引用，
  取消读取；返回原账号也不能恢复旧授权。无用户信息的静态目录可继续复用，
  该账号可用性须按新的认证上下文重新判断。

缓存容量不足可以淘汰最久未用的结果或预览；淘汰后再读属于允许的成本。
长期不变的目录/对象按版本复用，不为所有数据设置同一轮询周期。缓存不能
把未恢复、未收录或读取失败的内容伪装成完整覆盖。

搜索、预览或不同入口共享读取时，关闭一个入口只停止该入口的等待与发布，
不连带取消其他入口。同词新查询可以复用仍有效的分页 session；各入口保持
自己的浏览位置，旧查询取消和缓存淘汰都不能让迟到结果重新出现。

## 5. 问答与继续任务

### S-12 基于来源回答

AI 能理解意图、把自然语言转换成可编辑条件、提供已授权范围内的语义召回与更合适的排序，也能对明确提问给出有来源回答。语义检索和答案生成分别表达处理范围；模型失败或未配置时，关键词、附件名与功能检索仍可用。

输入关键词不会自动生成长回答；用户选择“基于这些内容回答”或主动提问后才进入 Ask。证据范围在提交时可见，回答放在结果内可展开的区域，不把首屏变成另一个默认聊天页。

按用户任务区分查找、回答和深入研究：明确名称/编号/功能名优先结果与直达，提交明确问题可自动给短答案并保留原结果，用户主动深入时才展开多轮研究和追问。意图不确定时保留查找结果并给“回答这个问题”的选择；模型只能在当前 actor 可读的域内证据上工作，不能借模型扩大可读范围。深入能力只在当前模型/来源具备时展示，不能以占位按钮承诺。

设备私有内容（E2EE 消息、端侧私密附件与记忆）只允许端侧处理，其正文与 embedding 不上传 Station 或外部模型；Station 侧内容是否允许交由已配置的 Station Agent provider（含外部模型商）处理，按来源显式授权并显示实际处理位置。原有通用 provider 配置不能自动代表已允许把全部域内内容发送给外部模型。没有可用端侧模型时，设备私有内容保留普通关键词检索，不静默改为远端处理。

回答必须引用本轮可读取的原对象/片段，区分没有证据、部分证据、矛盾与过期内容。没有来源时不伪造答案或引用。选择引用打开原位置；授权变化时引用停止预览，并使相关回答失效。

### S-13 后续操作

“问这个 Agent”“保存搜索”“打开 Applet”“在此会话继续”携带明确对象/上下文进入原域。任何创建/发送/删除等操作继续遵守该域的权限与确认，失败可恢复，不由 Search 自己写入业务。

## 6. 状态、恢复与个人控制

### S-14 可见状态

idle/recent、输入建议、searching、ready、empty、partial、offline、locked、failed、cancelled、permission changed 分别有明确含义。首次搜索即进入结果布局，不以命中决定是否“搜过”。

来源失败只影响该来源；可重试失败范围，保留已成功结果及输入。用户清除或换账号后，旧响应、预览、历史、AI 流不得回写。页面切换可保留同账号任务；锁屏与身份切换立即遮蔽私密结果。

### S-15 全局设置

`Settings → Search` 管理域内来源开关、可搜内容类别、私密索引、历史记录、AI 处理位置与外发授权、索引状态与重建。不提供搜索商、网络范围、OS 目录授权或外部 connector 配置；来源的连接认证仍由其原模块管理，Search 提供可达入口，不复制一套权限或 OAuth UI。

搜索词历史建议本机账号内默认关闭，最近访问与固定对象单独控制；这是待确认的隐私产品选择。启用后可清除、暂停，不能跨账号建议。索引重建不删除业务原文；移除来源应清理其 Search 派生产物。

## 7. 工艺与成功验证

继承 Peers UI Identity、LobeUI-first、现有 Shell 与 Prototype Lib。主结果使用低边框密度的连续行，稳定标题/片段/元数据轴；按需预览，避免隐藏挂载全部对象详情。视口缩放、长中文/英文、IME composition、屏幕阅读器、无障碍焦点、暗色与 reduced motion 都应在原型确认中覆盖。

目标入口与状态关系：

```text
普通启动 → Chat
Chat / 其他页 → 点击 Search → 轻量首屏 → 提交查询
                                     → 综合（人/会话/消息/Social/文档附件/Agent/Applet）/ 功能
                                     → 按需 AI 回答 / 预览 → 原对象
关闭或返回 → 触发前页面与上下文
```

需要确认的原型 Journey：Chat→Search→找人/功能→打开→返回；域内附件→名称/正文查询→原对象→撤权后消失；跨类型查询→筛选→消息 anchor；不完整恢复/断网→partial→重试；来源添加→收录→查询→移除；Ask→选择处理位置/外发授权→引用→权限变化。

后续产品验收以 S-01～S-18 对应行为为基准，由真实客户端和原对象 receiver 验证。
缓存复用还需记录来源 query、原文读取、权限校验、重复请求合并和恢复耗时，
区分首次、有效命中、过期与淘汰后的读取。指标目标需在基线后冻结：
time-to-open、首条可用结果、查询完成覆盖、Recall@10/MRR/NDCG、打开成功率、
权限错误和撤权泄漏。没有当前测量值，也不把本草案写成已达标。

## 8. 功能范围与支持边界

下列 required 是完整 Search 产品主张所要求的闭环，不是当前已实现或冻结的发布范围。

- **SEARCH-ENTRY / required**：Chat 默认落点，按钮按需进入；输入建议、关闭/返回、键盘与 Mobile 触摸连贯。入口不因来源或模型缺失消失。
- **SEARCH-FIND / required**：名称/短语/ID、别名与中文英文混合检索；范围、作者、时间、类型、位置筛选；综合排名、分页和 partial 状态。
- **SEARCH-OPEN / required**：人、消息/thread、域内附件/文档段落、帖子、Applet 与功能定位；已失权/移动/删除时有恢复动作，返回保留原查询。
- **SEARCH-REUSE / required**：重复查询、预览、已加载页和返回复用仍获准读取的
  数据；目录按版本失效，内容更新定向刷新，私密授权失效立即遮蔽。缓存不要求
  挂载页面，不改变历史默认值、Chat 默认落点或覆盖真实性。
- **SEARCH-CONTENT / required where connected**：Chat/人员/Social/Agent/Note/Applet 接入明确可搜字段，命中打开原对象。模块缺 provider 时不可宣称已经覆盖；消息只搜索本机已恢复且可读内容。所有来源以当前 actor 实时权限为前提。
- **SEARCH-ATTACHMENTS / required where owning module provides extraction**：Peers 管理附件的名称、类型、归属与时间检索；正文提取按所属模块声明的格式覆盖，父对象权限即附件权限，不提供 OS 目录选择或整机扫描。
- **SEARCH-FUNCTION / required**：按名称/别名/用途找当前账号可用的 Settings、模块与 Applet 功能，直达正确操作面。写操作由原域实施。
- **SEARCH-ANSWER / required when AI configured**：对明确问题给短答案和引用，证据仅来自当前 actor 可读的域内对象，可校验来源、停止与重试；不妨碍普通查找。无模型/证据/处理许可时明确不可用。
- **SEARCH-SEMANTIC / optional-advertised**：语义召回、自然语言条件与有界重排；能力声明包括实际来源/语种/执行边界（端侧或 Station），广告支持时必须证明；不支持的来源保留关键词路径。
- **SEARCH-SOURCE / required**：来源当前可用性、收录状态、范围、模型处理位置与历史控制；重建不删除原文，撤权停止预览/引用。
- **SEARCH-RESEARCH / optional-advertised**：用户明确进入的多轮域内检索、来源综合与追问；只有真实模型/检索能力可用时开放，预算与范围可见。
- **SEARCH-MEDIA / optional-advertised**：域内附件的 OCR、音视频转写、图片查询等格式能力单独声明；未支持不显示虚假正文覆盖。

公网搜索、外部网站/SaaS 资料库、OS 任意目录与整机扫描、跨设备访问他人设备文件、跨 actor/管理员全局检索、自动执行检索词中的发送/删除动作与无限资讯 Feed 均不属于 Search 承诺，也不以 Applet、connector 或“实验开关”形式进入来源集合。语料或模型缺口按来源显式降级，不能削减某个已承诺用户任务却继续称为完整。
