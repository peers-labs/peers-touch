## Goal And Slice Contract

Deliver one Station-owned Personal Agent OS. Every Task closes within four
agent-hours with a Home/Atelier action, Station identity/revision readback,
and both checks.

## Parallel Ownership

| Lane | Exclusive files while active |
|---|---|
| Station integration | shared proto/generated output, migrations, `agent.go`, shared EventBus, Acceptance registries |
| Home | `HomePage`, Home Goal components, `homeRuntime`, Home/Goal stores, Desktop Goal gateway, `packages/locales/*/agent.json` |
| Atelier | official Atelier controller/reducer/page/styles/locales and Atelier projection mapper |
| MCP prerequisite | bound MCP Plan; run while PAOS is quiescent, then prove on current HEAD |

Same-wave Tasks are read/write-disjoint. Generated files, routes, migrations,
Gate registries, and MCP integration are serialized.

## Atomic Cutovers

- Goal creation moves from task metadata to `AgentGoal`.
- Task rows migrate before writers/readers cut to `TaskRun`; legacy authorities
  delete only after Home, Atelier, and restart proof.
- Realtime cuts to outbox -> shared `EventBus` -> `/events/stream` -> projection.
- Goal completion moves to Station `GoalAcceptanceService` over immutable evidence.
- Rollback uses source/deployment rollback; no permanent dual truth remains.

## Release Criteria

- Desktop Native completes PAOS-J01 through PAOS-J04 with visible loading,
  empty, error, reconnecting, resync, stale, conflict, unauthorized, budget
  exhausted, partial, failed, cancelled, and accepted states.
- Home and Atelier show the same Goal revision, graph, TaskRuns, Needs You
  decision, budget, evidence, and Station verdict.
- Direct Model and one stateful external runtime use the same contracts.
- Restart, duplicate delivery, stale writer, actor/device isolation, overflow
  resync, cancellation, and L2 acceptance pass on exact source.
- Legacy task authorities and Agent-private fan-out have zero live references.
- UI copy is localized in English and Simplified Chinese; keyboard focus,
  labels, contrast, reduced motion, narrow layout, and draft preservation pass.
- Multi-Agent Canvas, Mobile, and unexecuted runtimes remain `UNPROVEN`.
