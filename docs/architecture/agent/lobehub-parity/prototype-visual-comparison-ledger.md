## Comparison Protocol

Each prototype surface must record:

| Field | Required evidence |
| --- | --- |
| LobeHub source | Exact `external/lobehub` file paths used for structure and state. |
| LobeHub live reference | App URL or browser tab used for visual/UX inspection. |
| Peers prototype reference | Prototype URL/query and screenshot inspected after the edit. |
| Matched | What is intentionally aligned. |
| Delta | What still differs. |
| Verdict | `blocked`, `revision-required`, `acceptable-delta`, `deferred`, or `ready-for-owner-review`. |

`acceptable-delta` is only allowed when the difference is caused by Peers-Touch architecture or UI Identity, not by missing fidelity work. `deferred` is only allowed when the Owner explicitly removes the surface from the current review scope; it must remain listed for later parity work and must not be claimed complete.
