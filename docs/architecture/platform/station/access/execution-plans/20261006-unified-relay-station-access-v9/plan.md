## Goal
让 Desktop 与 Mobile 安全识别直连 Station 或 Relay，固定同一 Home Station
identity，并复用同一 Access Gate 与业务 runtime。Relay 仅是最小、可撤销、有界且
不读取业务明文的 transport。

## Execution DAG
```text
SAL-REL-01-ROLE-SECURITY
  -> SAL-REL-02-STATION-ENROLLMENT
  -> SAL-REL-03-ENDPOINT-DISCOVERY
  -> SAL-REL-04-OPAQUE-TUNNEL
      -> SAL-REL-05-DESKTOP-BINDING
      -> SAL-REL-06-MOBILE-BINDING
          -> SAL-REL-07-NATIVE-ACCEPTANCE
```

Desktop 与 Mobile 仅在共享 protocol、enrollment 和 tunnel 完成后并行。

## Execution Contract

- `one` 是唯一 Linux/POSIX Relay service host；TLS、operator policy、密钥、存储、
  监管和配额证据均来自该 runtime。
- `sixwin` 仅运行 Windows Desktop 客户端；`three` 仅作为双 Station journey 的辅助
  Station。二者都不是 Relay service host。
- enrollment ready 后删除 header identity、明文 invite 和共享 JWT；opaque tunnel
  ready 后删除 transparent forward、client-token 与 authorization passthrough。
- 客户端绑定后不保留 URL-keyed identity 或平行 Relay registry。
- 仅当同一精确源码通过声明的原生、传输与攻击面 Acceptance 后关闭 Plan。
- v1-v8 仅保留为历史输入；v9 与后续 stable amendment 不恢复 Windows Relay host。
