# Client Control Plan Review Checklist

This checklist reviews the frozen Plan package. It is not execution progress or
a second task ledger.

- Product journeys CCP-J01 through CCP-J07 have owning vertical closures.
- Every Client Control decision is accepted and registered.
- NCP-D20, NCP-D21, SAL-D07, SAL-D08, and OLB-D18 remain upstream authorities.
- Contract generation precedes all consumers.
- Admin credentials cannot authorize publication.
- Suggestions never become verified Station entries without Station Access.
- Release metadata cannot initiate installation.
- Home/corpstable source and runtime ownership remain outside Client Control.
- Stable reset, unrelated cleanup, router mutation, paid hosting, push, PR,
  merge, and history rewrite are not authorized.
- Environment credential-like literals are removed and rotated before deploy.
- Functional checks precede formal Acceptance.
- API-only evidence does not claim native Desktop/Mobile UI proof.
- Every Task has bounded read/write sets, done conditions, failure behavior,
  claim boundary, and one Acceptance closure.
- The package passes Plan and architecture governance validation.
- The final digest is read back with `planctl inspect`.
