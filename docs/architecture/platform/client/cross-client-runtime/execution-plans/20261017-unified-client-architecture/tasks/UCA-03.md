## 完整闭环

Swift adapter 与 UCA-02 的 Kotlin adapter 实现同一 Rust-owned port contract。
本次以 Simulator build、launch、permission、terminate 和 relaunch 作为完成冒烟；
APNs provider、实体签名和物理设备行为留作发布阶段。

## Mechanical Amendment

UCA-01 已冻结共享 contract shape，但 Host 闭环仍必须修改其真实调用链：
Tauri plugin binding、Rust command normalization 与 TypeScript platform adapter。
上述文件纳入 writeSet，不改变 North Star，也不把 UIKit 或 product policy 暴露给
Web。原物理 Host Gate 保留为后续发布证据，但不再进入本 Plan 的 closure、
completion 或 smoke 判定。

Provider admission 继续校验 private APNs config；本次不配置或执行 APNs provider，
不声明实体签名应用或 provider delivery。
