## 完整闭环

Rust port contract 与 Mobile admission projection 先落地，Kotlin 只实现系统 API 和
callback normalization。冒烟只准备一次 Android build 与 Emulator，验证 install、
launch、permission、force-stop 和 relaunch，不扩展到推送或物理设备发布证明。

## Mechanical Amendment

UCA-01 已冻结共享 contract shape，但 Host 闭环仍必须修改其真实调用链：
Tauri plugin binding、Rust command normalization、TypeScript platform adapter 和
Mobile Shell back consumer。上述文件纳入 writeSet，不改变 North Star，也不授权
Android-specific business state。原物理 Host Gate 保留为后续发布证据，但不再进入
本 Plan 的 closure、completion 或 smoke 判定。

Provider admission 继续校验 private config，provider 私钥不进入 Gradle、Web 或
child capability。本次不配置或执行 FCM provider，不声明 provider delivery。
