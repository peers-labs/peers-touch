# 跨模块设计哲学总评与工艺加固（迁移增量 15）

> **Status**: draft · **Created**: 2026-10-31 · **Owner**: Client Platform · UI System
> **范围**：settings（6–9）→ chat（10–14）→ moments（4）全量走查；
> craft battery 从 C1–C13 扩到 C1–C15。

## 1. 设计哲学核对（不变量）

对三个模块逐项核对北极星不变量，全部成立：

- **材质分区，不用发丝线**：rail/feed/侧栏靠表面与模糊区分；分隔只在卡内（成员列表、
  媒体与开关之间）出现，Chrome 区零 border（C10 持续守护）。
- **琥珀唯一强调**：反应胶囊、发言描边、未读角标全部走 `--sk-accent`；
  危险操作两段确认统一 `#b0413a`（删除/挂断/录音红/上传失败），
  主操作（发送/接听主路径）走 `--sk-primary`。接听绿 `#3f9142` 仅用于来电接听，
  属「安全正向动作」语义，不与琥珀争强调。
- **方圆身份**：头像 `--sk-avatar-radius` 方角贯穿轨/气泡/通话格；表情/反应圆、
  通话圆钮按控件语义取圆，无混用。
- **无死控件**：inc12–14 新控件（操作条/表情格/草稿操作/语音/通话/附件）
  全部是原生 button 或包裹在 button 内，C12 选择器已同步扩面。
- **状态真实**：上传失败必须可重试可移除、录音权限失败有 Alert、
  附件下载只声称本地能做到的事；来电用显式「演示」入口而非伪造推送。
- **双宽**：全部场景跑 1360/390 溢出门；≤480 头部降级与单栏交换在增量 12 落地。

## 2. 本轮发现的系统性缺陷类别（已在 12–14 修复，15 固化为规则）

1. **半透明浮层穿透**：玻璃皮肤 `--sk-card-bg` 是 .66 白，侧拉页与悬浮操作条直接引用，
   消息流和 composer 透体重影。→ 新增 `--sk-overlay` 不透明 token（三皮肤），
   遮挡型浮层一律用它。新增 **C14 translucent-overlay**：
   `.sk-side-sheet`、`.sk-msg-actions-bar` 背景 alpha 必须 ≥.98。
2. **blob URL 所有权**：发送即转移给消息，草稿清理误回收导致图片 404、语音不可播。
   归产品约束，不做机器规则（状态时序不可静态判定）。
3. **match-all 空集拦截指针**：mention 空草稿 `include('')` 全匹配，候选层常驻截获点击。
   归交互正确性，已由 `msg-mention-pop` 场景防回归。
4. **窄宽死面**：≤1040 轨被全局 `display:none` 且无返回。→ 状态类驱动的单栏交换。
5. **无标签图标钮**：新增 **C15 icon-button-unlabeled**——所有无文本、含 glyph 的
   可见 button 必须有 aria-label/aria-labelledby/title。moments/settings/chat/通话
   全表面走查通过。
6. **点击热区**：inc12–14 新控件纳入 **C7 hit-target**（≥24px），
   发现 `.sk-draft-op` 22px 不达标，已修到 24px。
7. **死控件扩面**：**C12** AFFORDANCE_SELECTOR 增补操作条/表情格/工具钮/草稿操作/
   语音/通话/图片/文件/话题/共享媒体等 11 类新可点击元素。
