## 网络 Network

- **你的站点**：站点绑定卡（连接状态点）+ 已授权设备（QR 关联状态机：qr→核对码→finishing→complete/expired；每页 5 台、超出才出分页器；关联完成真实追加一行）+ 切换站点危险区两段确认。
- **发现**：可被发现主开关、各联邦可见性、谁可以联系你三分段。
- **联邦**：3 个种子卡（运营者/成员角色、站点数），展开看技术详情、运营者跳转诚实禁用（Station 未接线）、离开两段确认；加入联邦走端点校验（空/非法给内联错误）。

## AI

- **供应商**：左 260px 供应商列表（直连/CLI 标签、启用圆点）+ 右侧详情（启停、API Key 显隐、Base URL、模型行启停、添加模型、检查态 idle/checking/ok/fail）。
- **模型**：默认对话模型选择器。
- **发现**：3 个 Agent/Skill/MCP 包，安装/卸载真实切换，可搜索。
- **记忆**：启用开关、嵌入模型、SQLite/Postgres 后端（Postgres 显示 DSN + 连通测试）、向量/关键词权重双滑杆联动。
- **技能**：已安装/内置/市场三分类，GitHub/URL/ZIP 导入框（空输入禁用确认），市场安装、启停。
- **MCP**：服务器列表（stdio/http/sse 标签、工具数展开、测试态、启停、删除）+ 单个添加表单。

## 通道 Channels

- **机器人**（与真身 `desktop/shell/src/BotChannels.tsx` 对齐的凭据生命周期）：
  - 注册表行是固定三轨——身份（名称+状态 Tag，下方 `program/<id>` 发布标识与 `N 次/分` 同排元信息）｜尾部动作簇（启停 Switch、轮换密钥、吊销，均为 peers-ui 控件，吊销态行动作簇整体不渲染）。
  - **新建对话框只有 Bot 名称（带标签、autofocus）+ 头像（可选，hidden file input + peers-ui 触发钮）**；频率限制不是建时输入项（创建固定 60，注册表只读展示），禁止原生 number spin 框。确认钮语义为「生成通道与密钥」。
  - **凭据签发是新建的产品本质**：创建后立即弹出一次性凭据 Dialog——消息入口 `/v1/message-publishing/<publishingId>`、仅显示一次的 `ptb_` 密钥（默认掩码，可显隐、复制）、curl 速测片段、「我已保存，完成」收口；publishingId 撞名自动 `-2/-3` 后缀。
  - 轮换密钥走危险确认 Dialog，确认后弹出不含入口路径的新密钥 Dialog；吊销走危险确认 Dialog（密钥清除不可恢复）。注册表 localStorage 持久化。
  - **横向几何合同（无断点补丁）**：名称单行省略号、状态 Tag 永不折行（`.pt-tag` 原语 `white-space:nowrap; flex:0 0 auto`，唯一豁免是 expression candidate chip）、动作簇 `flex:0 0 auto`——任何宽度下被压缩的只可能是名称（省略号），标签永不逐字竖排。不允许用「在某宽度收缩侧栏」之类的过程化媒体查询补偿；自适应由三轨弹性结构本身保证，`widthSweep` 在 700–2880 每 24px 连续断言 Tag/名称/发布标识恒单行且设置滚动区零横溢。
- **飞书**：开通向导（域名→授权→开通三步）+ 已连接卡投递/入站开关 + 移除确认；Bots 通道仍显式挂起（信息提示，不做假入口）。

## 高级 Advanced

- **数据与存储**：4 条本地占用条；管理文件/导出在本地原型诚实禁用（Station 接线）；清缓存反馈；重置引导危险区两段确认。
- **统计**：4 汇总卡 + 4 周热力图（28 格固定数据）+ 3 张榜单。
- **日志**：全部/INFO/WARN/ERROR 过滤 + 关键词过滤；示例流（英文 seeded 原文）。
- **定时任务**：两条固定任务开关（每日摘要运行/每周备份暂停）。
- **命令面板**：内置 5 命令，可搜索、点击后关闭。
- **关于**：版本/构建/平台/运行时四元信息 + 四组能力折叠（消息/AI/网络/扩展）。
