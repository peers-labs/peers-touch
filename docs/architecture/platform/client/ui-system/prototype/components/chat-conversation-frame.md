## 1. 产品边界（全部 peers-ui，本地真实状态）

- **对话头部（增量 21 对齐 desktop ChatArea/微信，2026-11-05 修订）**：**一条 52px 头带
  （8px 框体顶距 + 44px 标题行），header 自身拥有顶距，与左侧目录轨头同一 y、同一 hairline，
  且 flush 到会话列顶（conv-view 无顶部 padding）**。旧的「conv-view 顶距 14px + 48px 独立
  header」把名字压在整条带约 60% 处，分隔线相对名字过低；现标题在带内居中、hairline 紧贴
  标题行下沿（微信比例）。名字（15.5px/650）与元数据（群：N 位成员；单人：在线/离线/
  免打扰）**同一基线行**，元数据是名字右侧 12px 灰色尾随注释（baseline 对齐、8px 间隔、
  不收缩），不独占第二行；**无头像**——头像只出现在每条对方气泡侧，不重复。3 个入口：
  语音、视频、会话详情（ⓘ）；≥721px 无返回钮。会话头不放搜索钮——聊天记录搜索统一收进
  资料卡**头部右上角的放大镜 icon**，全局找人/会话走外轨 ⌘K（列表常驻）；<720px 单栏交换时
  才出现返回。
- **聊天背景满幅（2026-11-05 修订）**：预设/上传壁纸是会话列的**满幅层**
  （`.sk-conv-view::before`，`inset:0`、直角、`cover`），从 header hairline 一直铺到列底，
  **不是内缩 22px 的 22px 圆角卡片**（旧实现四周留白缝，被判定为「丑/不占满」）。header
  在壁纸态铺不透明 overlay（壁纸止于 hairline），composer 区铺 92% overlay + blur 面纱保证
  输入可读；默认（无壁纸）不生成该层，外观不变。
- **1:1 通话浮层 `CallOverlay`**：ringing（1.6s）→ connecting（0.9s）→ active（计时），
  静音/摄像头开关（视频通话）、红色挂断；视频通话有本地预览位；取消呼叫/挂断后浮层消失。
- **聊天资料侧拉页（增量 44 按真身 `ChatDetailPanel.tsx` 重对齐）**：右侧 300px 浮层，
  侧拉头与聊天头**共线**（同顶 0、同高 52px、一条 hairline，标题 15.5px 在 44px 行内居中、× 绝对右上）。
  自上而下——身份 hero（72px 头像/群合成像带相机角标，owner/admin 可换；群名为 Hero 内联
  编辑而非弹窗，非管理员不可点）；权限卡（角色说明 + 群主/管理员/成员 Tag）；群成员格
  （owner/admin/member 排序、**viewer 自己必在成员列表**、名字下小字角色；成员超过 8 人时
  才出现查看全部；**添加成员与管理是头像格内的两个 38×38 方圆 icon 格（虚线 user-plus + 静音底
  settings），与成员头像同一 grid 流（微信范式），禁止文字行/整宽虚线按钮**；管理弹层可设/撤管理员、
  转让群主、两段确认移除）；设置卡全部为**15px 纯图标行**
  （我在本群的昵称内联编辑、消息免打扰、置顶）；**聊天背景[预设+上传+恢复]与查找聊天记录
  是侧拉头右上角的两个无边框 icon（图片/放大镜，紧邻关闭钮），不再占设置卡两整行**；
  共享媒体/文件卡；单人保留来电演示；危险区（清空 + 群聊退出/解散[owner 解散]、单人删除会话，
  均两段确认）。**群公告在真身聊天 UI 无入口，已删除**；开关轨行标记双向联动。
- **常驻双栏（增量 21，微信式）**：≥720px 点任何会话/人/群都是「左列表 + 右聊天」常驻，
  不出现返回钮、不把列表收走；<720px 才退回单栏 + 返回。
- **极端挤压回流（2026-11-05，微信范式）**：任何宽度下**禁止固定最小宽/横向裁剪**。
  `.sk-chat-feature` 为 `min-width:0`，main→conv-view→stream→消息行/列/气泡→composer 全链
  `min-width:0`；消息流是唯一滚动宿主（`overflow-x:hidden; overflow-y:auto`），气泡
  `overflow-wrap:anywhere` 换行、状态元信息行 `flex-wrap`，长 token 不撑列。≤720 单栏交换时
  grid 列位重置为第 1 列（否则隐式空轨把会话顶到框体中部），侧内边距收到 14/10，头部动作缩到
  32px，≤480 隐藏视频/详情入口、气泡放宽到 88%；资料/话题侧拉 ≤560 满幅覆盖（不留不可读
  窄条）。回归场景 `chat-reflows-under-squeeze`（viewport op 560/400，断言无横向溢出、main
  填满、自身头像在框内、侧拉满幅）。
- **消息头像身份名片（2026-11-05，微信范式）**：消息流里对方/自己的头像都不是死控件——点击弹与动态面
  **同一个共享身份名片**（identity/IdentityCard）：身份/bio/粉丝/互关 + **最近动态**缩略格 +
  「发消息」（留会话）+「查看主页」与动态格跨面跳到动态面个人页（DesignDirections 经
  momentsNav 路由）。弹层定位由 peers-ui Overlay 负责，视口优先翻转：消息流是滚动 clip frame，
  下方空间不足时名片向上翻转并允许越过 clip 顶（fixed portal 不被其裁剪），保证整卡在屏内。
- **消息搜索 Dialog**：关键词过滤本会话非服务消息，空查询给最近 5 条；结果行（发送者/摘要/时间）可点。
- **话题侧拉页**：种子消息 + 3 条种子回复 + 回复输入框；发送后回复 +1、入口计数联动、输入清空。
- 服务消息（入群/建群）以居中胶囊渲染。
- **窗内偏好与多语言（增量 22）**：聊天根 `.sk-chat-feature` 带 `data-locale`
  与 `data-message-layout`；界面 chrome 文案全部经 `prefs.ts` 字典 t() 化
  （zh-CN/en），种子消息/名单保持 authored 原文不译；时间格式随 locale。
- **消息对齐偏好（增量 22）**：「各在一边」为默认（peer 左/me 右）；
  「统一靠左」时 me 行 `align-self:flex-start`、内容列左对齐，工具条随之改挂右侧。
  偏好 localStorage 持久化，设置改动经事件广播即时作用到已挂载的聊天面。
- **消息行对齐（增量 20 回归 desktop ChatArea）**：`.sk-msg` 为 flex 行，
  `align-items: flex-start`——对方头像与气泡顶平齐；群聊时头像与发送者名顶平齐；
  纯 emoji 大行例外，底对齐（desktop parity）。头像统一 32px（含撤回墓碑、typing）。
  时间戳在气泡**外**的 meta 行（气泡下方，与已编辑/投递状态/反应同列），
  不再画进气泡内部。

## 2. 旧设计审计

- 桌面端详情/Thread 是独立大面板；原型统一为 `.sk-side-sheet` 同位侧拉页（绝对定位、
  不挤占对话列），关闭控件与分隔节奏一致。
- 通话状态机保留 desktop 的阶段语义（振铃/接通/通话中），用确定性定时器模拟，
  不做假的立即接通；浮层用深色玻璃材质覆盖对话列而非整窗，符合窗框内应用边界。
- 网格布局显式列位（增量 20 起：rail 在左 300px 列、main 在右 1fr 列，
  对齐 desktop SocialChatPage 的左轨右话序），修复了子元素自动放置
  把中栏压进 300px 轨道的缺陷；me 气泡列右对齐补全。
