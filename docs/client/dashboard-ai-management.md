# Station AI 管理与使用

管理员在 Station Dashboard 的「AI 服务商」管理共享服务商、模型、凭据和
使用权限。普通 Desktop 用户在 Settings 查看已授权模型，并选择自己的默认模型。

## 管理员配置

部署时先通过 Station 的私有配置提供稳定的 `PT_SECRET_KEK`，或使用挂载文件
及 `PT_SECRET_KEK_FILE`。密钥需随数据库备份妥善保存，重建容器时保持不变。
旧凭据首次加密迁移需要该密钥；缺失时 Station 拒绝启动。

登录 Dashboard 后打开「AI 服务商」，选择内置服务商，或添加一个直连 API
服务商。填写 API 基础地址、名称和启用状态，保存配置。

在「凭据」输入新密钥并保存。密钥加密保存在 Station；保存后只能看到配置
状态。替换密钥需重新输入完整值。移除凭据会使依赖它的用户暂时无法调用。

直连服务商支持添加、编辑和启用模型。CLI 模型由适配器发现，不能手动改写。
添加自定义模型时，填写供应商声明的上下文 token 数；必须为大于 1 的整数。
未填写或非法数值不能保存，不能把安装状态当作模型可用的证明。
选择 CLI 服务商时，可编辑适配器允许的默认模型、附加参数、环境选项和超时。
模型和密钥不能放入附加参数或环境选项。

在「服务商使用权限」添加授权。每项授权指定全部已认证用户或一个 Actor PTID，
以及全部模型或一个模型。授权列表为空时，所有普通用户都无法使用。保存时
如果提示配置冲突，刷新并确认最新配置后重新操作。

共享服务商的同名资源优先。撤销共享授权不会切换到用户自己的同名服务商。
已发出的调用可以完成，后续调用重新检查授权。

## CLI 安装

「CLI 适配器」保留 TRAE CLI、Codex、Cursor 和 Claude Code 四个选项。
点击支持自动安装的适配器，选项背景展示实际安装进度。失败时点击「重试」，
或查看官方指南。TRAE CLI 当前按官方指南手动安装。

适配器安装在 Station，一次安装供授权用户使用。用户的配置、缓存、临时文件
和工作目录各自独立。Station 主机已有的 CLI 登录状态不会自动成为共享授权。
安装完成后，仍需配置该适配器的凭据、发现模型并授予使用权限。

## 普通用户使用

在 Desktop Settings 的 Provider 区域查看 Station 授权的服务商和模型。
共享资源为只读；需要增加模型、配置密钥或安装适配器时，由 Station 管理员
在 Dashboard 完成。

在 AI / Models 选择默认服务商和模型。默认值保存到当前账号，同一账号的其他
设备可读取。Agent、composer 和 Cron 的模型选择均保留服务商与模型的组合身份。

也可以在已授权模型列表点击「设为默认」。普通页面显示模型名称和个人选择，
不显示运行方式、凭据配置或安装控制。暂无模型时联系管理员开放权限。
加载失败时使用页面的「重试」；原模型失去授权后，选择其他可用模型。

管理员默认关闭「允许个人服务商」。启用后，用户可管理自己的个人服务商和
凭据。个人资源仍与其他用户隔离，且共享同名服务商保留优先级。

## Federation

Dashboard 的「联邦」支持创建、加入、查看成员、离开和归档。离开或归档仍需
满足联邦治理规则；账本主 Station 未移交职责时不能直接离开。

普通 Desktop 在「查找好友」使用当前可用的联邦上下文。Settings 不提供联邦
管理入口。
