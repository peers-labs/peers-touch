Architecture & Routing:
- Framework: React + Tailwind CSS + Framer Motion + Lucide React.
- Device: Mobile (390x844).
- Routes:
  - `/login`: QR Code Login.
  - `/home`: Home (Search + Navigation).
  - `/im`: IM Chat List.
  - `/im/chat`: IM Chat Detail.
  - `/ai`: AI Chatbot.
    - `?step=0`: Initial
    - `?step=1`: Thinking
    - `?step=2`: Answered
    - `?selector=open`: Agent Selector Dropdown
  - `/settings`: Settings.
- Layout: Bottom tab bar for main pages (/home, /im, /ai, /settings).
