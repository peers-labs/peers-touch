# Login Page Redesign PRD
## Overview
A modern desktop login interface centered around an account selection/confirmation step.

## Features
1. **Header**: Progress indicator (dots), main action icon (sign in).
2. **Typography**: Clear title "Sign in to start" and descriptive subtitle.
3. **Account Section**:
   - "Switch Account" button.
   - Active account card displaying: Avatar, Username, Status badge (Active), Provider info (GitHub + Email), Authorization/Refresh timestamps.
   - Card actions: Refresh, Sign Out.
4. **Footer Actions**: "Skip" and "Continue" buttons.

## Design System
- **Colors**: Slate/Gray scale for neutrals, Blue for primary actions, Red for destructive (Sign Out), Green for positive status.
- **Typography**: Inter-like sans-serif, clear hierarchy.
- **Layout**: Centered card on a subtle background, generous padding, rounded corners (modern feel).
