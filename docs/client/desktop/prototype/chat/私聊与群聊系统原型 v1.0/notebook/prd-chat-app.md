# Chat App PRD
## Overview
A modern desktop web application for private and group messaging.

## Layout Structure
- **Left Navigation**: Main tabs (Messages, Contacts, Statistics, Settings).
- **Session List (Middle)**: Search, Filter tabs (All, Direct, Groups), List of conversations with avatars, names, last message, time, unread badges, online status.
- **Main Chat Area**:
  - **Header**: Chat title, status/members, actions (Search, Info).
  - **Message History**: Message bubbles, timestamps, read receipts, quoted messages.
  - **Input Box**: Text area, attachments, send button.
- **Right Panel (Contextual)**: Group info, member list, settings, statistics.

## Key Interactions
- Switching between chats.
- Viewing group details / member management.
- Sending a message (with quote simulation).
- Viewing statistics.
