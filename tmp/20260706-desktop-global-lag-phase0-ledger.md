## Scope

Phase 0 only builds the Station-managed Desktop frontend telemetry substrate, observability, sampling, fail-closed preflight, baseline runners, and reports.

Out of scope before confirmation:

- No Shell/PageHost/SectionHost/Store/Overlay behavior changes.
- No component-level optimization patches.
- No claim that browser/gateway samples are Tauri WebView true-click samples.

## Required Output

- Runtime event stream: `window.__PT_FRONTEND_RUNTIME_EVENTS__`
- Station ingestion contract: Desktop -> Gateway -> Station telemetry batch upload.
- Station storage contract: raw frontend telemetry event table and aggregate rollup table/view.
- Station query contract: trace lookup by actor/session/device/module/interaction/time window.
- Dev mirror: `tooling/acceptance/reports/desktop-performance-latest.json`
- Dev mirror: `tooling/acceptance/reports/desktop-performance-latest.md`
- Gate checklist: Station-managed telemetry, interaction correlation, sampler families, matrix preflight, red-line report.
- Completion audit: scope done/partial/unproven/out-of-scope.

## Reuse Contract

- Station owns ingestion, persistence, retention, aggregation, query, and user/operator analysis.
- Desktop owns only local buffering, batching, retry, and E2E inspection.
- `tooling/acceptance/reports/*` is only a local/CI mirror of the Station event schema; it is not the user-facing telemetry sink.
- The telemetry substrate must be shared by Shell, PageHost, SectionHost, Overlay, Store, Invoke, Runtime, Applet, and Acceptance modules.
- No module may create a private global telemetry buffer or private upload path for equivalent frontend lifecycle or interaction evidence.
- Performance diagnosis is only the first consumer; module acceptance, feature debugging, runtime health, PR quality evidence, and user/support trace lookup must consume the same Station-managed event stream.
- Every event must carry `schemaVersion`, `kind`, `source`, `module`, `runtime`, actor/session/device scope when authenticated, and optional `interactionId`.
- Sensitive payloads are forbidden; use ids, counts, durations, state names, and redacted error classes.

## Known Blockers To Preserve In Reports

- Tauri true-click is blocked by macOS Assistive Access/screenshot restrictions unless WebView telemetry is added.
- Production preview currently crashes before ready shell, so prod performance samples cannot be emitted.
- Offline/no-gateway currently reaches boot failed screen, not ready shell.
- Existing runtime profiler still lacks full OverlayHost coverage beyond the instrumented Chat context-menu trigger subtree, live commit aggregation evidence, live store fanout aggregation evidence, live longtask/layout/paint exception evidence, live runtime invoke classification aggregation evidence, and live DOM automation evidence for overlay visible events/latency.
- P0c matrix runner currently proves fail-closed reporting only; it does not start Station/Desktop, does not emit samples, and does not prove browser-gateway, Tauri WebView, prod preview, or offline fixture performance.
- P0c red-line policy currently proves policy shape and fail-closed behavior only; it does not prove any budget has been met because no sampled raw event set exists.
- P0c report writer currently proves Dev/CI report assembly only; it does not prove Station has live sampled raw events or rollups for Desktop lag scenarios.
